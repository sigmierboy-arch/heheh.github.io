🎨 Что такое CSS и как его подключить

🎯 Цель урока

Понять, что такое CSS, зачем он нужен, и научиться подключать стили к HTML-странице тремя разными способами.

📚 Теория

CSS (Cascading Style Sheets) — это язык стилей, который отвечает за внешний вид веб-страницы. Если HTML — это скелет, то CSS — это кожа, одежда и макияж! 💅

Три способы подключить CSS:

  1. Встроенные стили (inline) — атрибут style прямо в HTML-теге: 
    <p style="color: red;">Красный текст</p>
  2. Внутренние стили (internal) — тег <style> в <head>: 
    <head>
    <style>
        p {
            color: blue;
            font-size: 18px;
        }
    </style>
</head>
  3. Внешние стили (external) — отдельный .css файл (ЛУЧШИЙ способ!): 
    <head>
    <link rel="stylesheet" href="styles.css">
</head>

🔍 Разбор синтаксиса CSS:

p {
    color: blue;
    font-size: 18px;
}
  • p — селектор (ЧТО стилизуем)
  • color: blue; — свойство: значение; (КАК стилизуем)
  • Всё внутри фигурных скобок — блок объявления стилей

💡 Полезный совет:

Всегда используй внешний .css файл! Это как хранить всю одежду в шкафу, а не разбрасывать по комнате. Отделяй структуру (HTML) от оформления (CSS).

⚠️ Типичная ошибка:

Забыть точку с запятой ; в конце свойства. Без неё следующее свойство может не сработать!
Плохо: color: red font-size: 18px;
Хорошо: color: red; font-size: 18px;

✅ Итоги урока:

  • CSS — язык стилей для оформления HTML
  • 3 способа подключения: inline, internal, external
  • Внешний .css файл — лучший выбор
  • Синтаксис: селектор { свойство: значение; }

🧠 Самостоятельная работа:

  1. Создай HTML-страницу с тремя параграфами. Подключи внешний CSS-файл и задай всем параграфам синий цвет текста.
  2. Одному из параграфов добавь встроенный стиль (inline) с красным цветом. Заметь, какой стиль победил.
  3. Создай ещё одну страницу и подключи тот же CSS-файл. Убедись, что стили применились и там.

🤖 Вопрос к размышлению:

Как ты думаешь, почему внешний CSS-файл считается лучшей практикой, даже если страница всего одна?

🎉 Бонус:

Ты только что открыл дверь в мир дизайна! Твои серые HTML-страницы скоро засияют всеми цветами радуги. Вперёд! 🚀
