🧊 Позиционирование: static, relative, absolute, fixed, sticky

🎯 Цель урока

Освоить все типы позиционирования (static, relative, absolute, fixed, sticky) и свойство z-index.

📚 Теория

position — как элемент ведёт себя в потоке:

  1. static (по умолчанию) — обычное поведение. top/left/right/bottom не работают.
  2. relative — сдвигается ОТНОСИТЕЛЬНО своего обычного места:
    .box {
    position: relative;
    top: 10px;   /* сдвинули вниз на 10px */
    left: 20px;  /* сдвинули вправо на 20px */
}
  3. absolute — «вырывается» из потока, позиционируется относительно ближайшего позиционированного предка:
    .child {
    position: absolute;
    top: 0;
    right: 0;  /* прилип к правому верхнему углу родителя */
}
.parent {
    position: relative;  /* чтобы absolute считал от него! */
}
  4. fixed — фиксируется относительно ОКНА БРАУЗЕРА:
    .header {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;  /* прилип к верху, всегда виден */
}
  5. sticky —«прилипает» при прокрутке:
    .nav {
    position: sticky;
    top: 0;  /* как только доходит до верха — прилипает */
}
z-index — кто сверху (работает ТОЛЬКО с позиционированными элементами): 
.modal {
    position: fixed;
    z-index: 1000;  /* поверх всего */
}

🔍 Разбор:

  • static — обычный поток
  • relative — сдвиг от своего места (место сохраняется)
  • absolute — позиция от предка с position: relative
  • fixed — позиция от окна браузера
  • sticky — гибрид relative и fixed
  • z-index — слои (чем больше, тем выше)

💡 Полезный совет:

Если absolute ведёт себя не так, как ожидаешь — проверь, задан ли родителю position: relative. Без этого absolute будет считать от <body>!

⚠️ Типичная ошибка:

Думать, что z-index работает всегда. Нет! Только для элементов с position, отличным от static. Проверь это первым делом!

✅ Итоги урока:

  • static — по умолчанию
  • relative — сдвиг от своего места
  • absolute — от позиционированного предка
  • fixed — от окна браузера
  • sticky — прилипает при прокрутке
  • z-index — слои

🧠 Самостоятельная работа:

  1. Создай блок с position: relative и внутри него — блок с position: absolute. Помести дочерний блок в правый нижний угол.
  2. Создай «липкую» шапку с position: sticky; top: 0;. Добавь много текста и проверь, что шапка прилипает при прокрутке.
  3. Создай модальное окно (поверх всего) с position: fixed и z-index: 1000.

🤖 Вопрос к размышлению:

Почему sticky не работает, если у родителя задан overflow: hidden?

🎉 Бонус:

Позиционирование — это управление пространством. Теперь ты можешь разместить элемент в любом месте экрана. Это как телекинез! 🧙‍♂️
