🔄 Flexbox часть 1: Знакомство и оси

🎯 Цель урока

Понять модель Flexbox и научиться выравнивать элементы по главной и поперечной осям.

📚 Теория

Flexbox — это революция в вёрстке! Забудь про float и inline-block с их хаками. Flexbox создан для удобного расположения элементов в строку или колонку.

Как включить:

.container {
    display: flex;  /* магия! */
}
Все прямые дочерние элементы становятся flex-элементами и выстраиваются вдоль главной оси (по умолчанию — горизонтально).

Свойства контейнера:
  • flex-direction — направление главной оси:
    flex-direction: row;            /* слева направо (по умолч.) */
flex-direction: row-reverse;    /* справа налево */
flex-direction: column;         /* сверху вниз */
flex-direction: column-reverse; /* снизу вверх */
  • justify-content — выравнивание по ГЛАВНОЙ оси:
    justify-content: flex-start;    /* в начале (по умолч.) */
justify-content: flex-end;      /* в конце */
justify-content: center;        /* по центру */
justify-content: space-between; /* по краям, равные промежутки */
justify-content: space-around;  /* равные отступы вокруг */
justify-content: space-evenly;  /* равные отступы везде */
  • align-items — выравнивание по ПОПЕРЕЧНОЙ оси:
    align-items: stretch;      /* растянуть (по умолч.) */
align-items: flex-start;   /* в начале */
align-items: flex-end;     /* в конце */
align-items: center;       /* по центру */
align-items: baseline;     /* по базовой линии текста */

🔍 Разбор:

  • display: flex — включаем флекс-контейнер
  • Главная ось — вдоль неё выстраиваются элементы
  • Поперечная ось — перпендикулярно главной
  • justify-content — двигаем ПО ГЛАВНОЙ
  • align-items — двигаем ПО ПОПЕРЕЧНОЙ
  • space-between — первый и последний прижаты к краям

💡 Полезный совет:

Три волшебные строчки для идеального центрирования:

.container {
    display: flex;
    justify-content: center;
    align-items: center;
}
Элемент будет ровно по центру родителя. Забудь про муки с margin: auto!

⚠️ Типичная ошибка:

Забыть, что align-items работает по ПОПЕРЕЧНОЙ оси. Если главная ось горизонтальная (row), то align-items двигает по вертикали, и наоборот.

✅ Итоги урока:

  • display: flex — включаем Flexbox
  • flex-direction — направление главной оси
  • justify-content — по главной оси
  • align-items — по поперечной оси
  • Три строчки = идеальное центрирование

🧠 Самостоятельная работа:

  1. Создай контейнер с 5 элементами. Включи Flexbox и поиграйся со всеми значениями justify-content.
  2. Создай контейнер высотой 400px. Выровняй элементы по центру и вертикали с помощью align-items.
  3. Сделай навигационное меню: логотип слева, ссылки справа (используй justify-content: space-between).
