🔄 Flexbox часть 2: flex-wrap, align-content, gap, свойства элементов

🎯 Цель урока

Освоить продвинутые возможности Flexbox: перенос элементов, выравнивание строк, зазоры и управление размерами flex-элементов.

📚 Теория

Свойства контейнера (продолжение):

flex-wrap — перенос на новую строку:

.container {
    flex-wrap: nowrap;  /* всё в одну строку (по умолч.) */
    flex-wrap: wrap;    /* переносить */
    flex-wrap: wrap-reverse; /* переносить в обратном порядке */
}
align-content — выравнивание СТРОК (работает только с flex-wrap: wrap):
align-content: center;
align-content: space-between;
gap — зазор между элементами (СОВРЕМЕННО! 🔥):
.container {
    gap: 20px;  /* отступы между всеми элементами */
    gap: 20px 30px;  /* row-gap column-gap */
}

Свойства flex-элементов:

flex-grow — способность расти (0 — не расти):
.item {
    flex-grow: 1;  /* займёт всё доступное пространство */
}
flex-shrink — способность сжиматься (1 — сжиматься):
flex-basis — базовый размер:
.item {
    flex-basis: 200px;  /* начинаем с 200px */
}
Сокращение flex:
.item {
    flex: 1 1 200px;
    /* flex-grow flex-shrink flex-basis */
}
align-self — индивидуальное выравнивание:
.special {
    align-self: flex-end;  /* только этот элемент уйдёт вниз */
}
order — порядок (чем меньше, тем раньше):
.first {
    order: -1;  /* станет первым */
}

🔍 Разбор кода по косточкам:

  • flex-wrap: wrap — если не влезают, переносим
  • gap: 20px — современная замена margin для flex-элементов
  • flex-grow: 1 — все элементы разделят свободное место поровну
  • flex: 1 — сокращение для flex-grow: 1; flex-shrink: 1; flex-basis: 0
  • order — меняет порядок визуально, не меняя HTML

💡 Полезный совет:

Используй gap вместо margin у flex-элементов. Не будет лишних отступов по краям, и код чище!

А flex: 1 на всех элементах — и они разделят ширину поровну. Магия равных колонок!

⚠️ Типичная ошибка:

Забыть, что align-content работает только с flex-wrap: wrap. Если элементы в одну строку — используй align-items.

✅ Итоги урока:

  • flex-wrap: wrap — перенос строк
  • gap — отступы между элементами
  • flex-grow — растягивание
  • flex — сокращённая запись
  • align-self — индивидуальное выравнивание
  • order — порядок

🧠 Самостоятельная работа:

  1. Создай галерею карточек с flex-wrap: wrap. Карточки должны переноситься на новую строку, если не влезают.
  2. Создай три колонки с помощью flex: 1. Убедись, что они всегда одинаковой ширины.
  3. Используй order, чтобы визуально поменять местами два элемента (не меняя HTML)

🤖 Вопрос к размышлению:

Почему gap лучше, чем margin для отступов между flex-элементами?

🎉 Бонус:

Ты освоил Flexbox на 100%! Теперь ты можешь верстать навигации, галереи, карточки и даже целые страницы. Flexbox — твой лучший друг! 🤝
