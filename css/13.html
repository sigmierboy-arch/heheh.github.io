📐 CSS Grid часть 1: Сетка, колонки и строки

🎯 Цель урока

Понять двумерную модель Grid и научиться создавать сетки с колонками и строками.

📚 Теория

CSS Grid — это ДВУМЕРНАЯ система раскладки. Flexbox — для одной оси (строка ИЛИ колонка). Grid — для двух осей одновременно (строки И колонки).

Как включить:

.container {
    display: grid;  /* магия сетки! */
}

Определяем колонки и строки:

.container {
    display: grid;
    grid-template-columns: 200px 1fr 1fr;
    grid-template-rows: 100px auto 100px;
    gap: 20px;
}

Единицы измерения для Grid:

  • px — фиксированные пиксели
  • fr — доля свободного пространства (fraction) 🔥
  • % — проценты
  • auto — по содержимому
  • repeat(3, 1fr) — повторить 3 раза по 1fr

Функция repeat():

grid-template-columns: repeat(4, 1fr);
/* 4 одинаковые колонки */

grid-template-columns: repeat(3, 200px);
/* 3 колонки по 200px */

minmax():

grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
/* адаптивная сетка! Сама решает, сколько колонок влезет */

🔍 Разбор:

  • grid-template-columns — сколько колонок и какой ширины
  • grid-template-rows — сколько строк и какой высоты
  • 1fr — «возьми одну долю оставшегося места»
  • repeat(3, 1fr) — создай 3 колонки по 1fr
  • gap — зазор между ячейками
  • minmax(200px, 1fr) — не меньше 200px, не больше 1fr

💡 Полезный совет:

Используй fr для адаптивных раскладок. Сетка на fr сама пересчитывается при изменении размера экрана. Никаких калькуляторов!

Шпаргалка: repeat(auto-fill, minmax(250px, 1fr)) — сама добавляет/убирает колонки при ресайзе!

⚠️ Типичная ошибка:

Путать Grid и Flexbox. Grid — для раскладки ВСЕЙ страницы (строки и колонки). Flexbox — для компонентов (выравнивание в одну линию). Они друзья, а не конкуренты!

✅ Итоги урока:

  • display: grid — включаем сетку
  • grid-template-columns — колонки
  • grid-template-rows — строки
  • fr — доля пространства
  • repeat() — повторение
  • minmax() — мин/макс размер

🧠 Самостоятельная работа:

  1. Создай сетку 3×3 с помощью Grid. Используй repeat(3, 1fr) для колонок.
  2. Создай макет страницы: шапка (полная ширина), контент + сайдбар (2 колонки), подвал (полная ширина).
  3. Создай адаптивную галерею с repeat(auto-fill, minmax(250px, 1fr)). Поиграй с шириной окна.
