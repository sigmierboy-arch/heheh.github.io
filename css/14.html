📐 CSS Grid часть 2: Размещение элементов, области, выравнивание

🎯 Цель урока

Научиться точно размещать элементы в Grid-сетке по номерам линий, использовать именованные области и выравнивать сетку.

📚 Теория

  1. Размещение по линиям:
    .item {
    grid-column-start: 1;
    grid-column-end: 3;    /* займёт колонки 1-2 */
    grid-row-start: 2;
    grid-row-end: 4;       /* займёт строки 2-3 */
}
/* Сокращённо: */
.item {
    grid-column: 1 / 3;
    grid-row: 2 / 4;
}
/* Ещё короче (span — на сколько растянуть): */
.item {
    grid-column: span 2;  /* растянуть на 2 колонки */
}
  2. 2. Именованные области (grid-template-areas) 🔥:
    .container {
    display: grid;
    grid-template-areas:
        "header header header"
        "sidebar main main"
        "footer footer footer";
    grid-template-columns: 200px 1fr 1fr;
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }
    Это буквально РИСУНОК макета текстом! 🎨
  3. 3. Выравнивание всей сетки:
    .container {
    justify-content: center;  /* сетка по центру горизонтально */
    align-content: center;    /* сетка по центру вертикально */
    place-content: center;    /* оба сразу */
}
  4. Выравнивание ячеек:
    .container {
    justify-items: center;  /* элементы внутри ячеек по горизонтали */
    align-items: center;    /* элементы внутри ячеек по вертикали */
    place-items: center;    /* оба сразу */
}

🔍 Разбор:

  • grid-column: 1 / 3 — от первой линии до третьей (займёт 2 колонки)
  • grid-template-areas — визуальное описание макета текстом!
  • grid-area — имя, которое привязывается к области
  • place-content — выравнивание всей сетки внутри контейнера
  • place-items — выравнивание элементов внутри ячеек

💡 Полезный совет:

Используй grid-template-areas для макетов страниц. Это настолько наглядно, что ты буквально «рисуешь» структуру. Особенно круто для адаптива (просто переопредели области в медиа-запросе)!

⚠️ Типичная ошибка:

Забыть, что линии считаются не от 0, а от 1! Первая линия — 1, вторая — 2. И область с grid-column: 1 / 3 займёт ДВЕ колонки (от первой линии до третьей).

✅ Итоги урока:

  • grid-column/row — размещение по линиям
  • grid-template-areas — макет текстом
  • grid-area — имя области
  • place-content — выравнивание сетки
  • place-items — выравнивание в ячейках

🧠 Самостоятельная работа:

  1. Создай макет сайта через grid-template-areas: шапка, меню, контент, сайдбар, подвал.
  2. Размести элемент так, чтобы он занимал 2 колонки и 2 строки.
  3. Используй place-items: center, чтобы все элементы в ячейках были по центру.

Почему grid-template-areas так удобно для адаптивной вёрстки?
