🔗 Псевдоклассы: :hover, :active, :focus, :nth-child, :not

🎯 Цель урока

Освоить псевдоклассы CSS для стилизации интерактивных состояний и выбора элементов по позиции.

📚 Теория

Псевдокласс начинается с двоеточия и описывает СОСТОЯНИЕ элемента.

Интерактивные псевдоклассы:

a:hover {
    color: red;  /* при наведении мыши */
}
button:active {
    transform: scale(0.95);  /* при нажатии */
}
input:focus {
    outline: 2px solid blue;  /* в фокусе (клавиатура/мышь) */
}
a:visited {
    color: purple;  /* посещённая ссылка */
}

Псевдоклассы позиции (очень мощные! 🔥):

li:first-child { ... }   /* первый элемент */
li:last-child { ... }    /* последний элемент */
li:nth-child(2) { ... }  /* второй элемент */
li:nth-child(odd) { ... }  /* нечётные (1,3,5...) */
li:nth-child(even) { ... } /* чётные (2,4,6...) */
li:nth-child(3n) { ... }   /* каждый третий */
li:nth-child(3n+1) { ... } /* 1, 4, 7, 10... */

Другие полезные псевдоклассы:

p:first-of-type { ... }  /* первый параграф в родителе */
div:empty { ... }        /* пустой элемент */
:not(.special) { ... }   /* все, КРОМЕ .special */

🔍 Разбор:

  • :hover — курсор над элементом
  • :active — момент нажатия
  • :focus — элемент активен (клавиатура/таб)
  • :nth-child(odd) — нечётные дети
  • :not(.class)— исключение
  • :first-of-type — первый СВОЕГО ТИПА (не любой первый)

💡 Полезный совет:

Используй :nth-child(odd) для полосатых таблиц (зебра-стиль):

tr:nth-child(even) {
    background-color: #f2f2f2;
}

А :not() — отличный способ применить стили ко всем, кроме одного.

⚠️ Типичная ошибка:

Путать :first-child и :first-of-type. Первый ищет ЛЮБОЙ первый элемент, второй — первый элемент КОНКРЕТНОГО ТИПА. p:first-child сработает, только если параграф действительно первый ребёнок.

✅ Итоги урока:

  • :hover — наведение
  • :active — нажатие
  • :focus — фокус
  • :nth-child() — по позиции
  • :first-child, :last-child
  • :not() — исключение

🧠 Самостоятельная работа:

  1. Стилизуй ссылки: обычный цвет, :hover (другой цвет), :visited (третий цвет).
  2. Создай список из 10 элементов и раскрась чётные строки в светло-серый.
  3. Создай 5 карточек. С помощью :not() задай фон всем, кроме третьей.
