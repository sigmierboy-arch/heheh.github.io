🎭 Псевдоэлементы: ::before, ::after, ::placeholder, ::selection

🎯 Цель урока

Освоить псевдоэлементы для добавления декоративного контента и стилизации отдельных частей элементов.

📚 Теория

Псевдоэлементы (с двумя двоеточиями) создают «виртуальные» элементы, которых нет в HTML.

::before и ::after — короли псевдоэлементов! 🔥
Добавляют контент ДО и ПОСЛЕ содержимого элемента. Требуют свойство content!

.quote::before {
    content: "«";
    font-size: 24px;
    color: gold;
}
.quote::after {
    content: "»";
    font-size: 24px;
    color: gold;
}

Декоративные элементы:

.button::after {
    content: " →";  /* добавили стрелку */
}
.divider::before {
    content: "";
    display: block;
    width: 100%;
    height: 1px;
    background: #ccc;
    margin-bottom: 10px;
}

Другие псевдоэлементы:

input::placeholder {
    color: #999;
    font-style: italic;  /* стилизуем placeholder */
}
::selection {
    background: yellow;
    color: black;  /* цвет выделения текста */
}
p::first-letter {
    font-size: 3em;
    color: red;
    float: left;  /* буквица */
}
p::first-line {
    font-weight: bold;  /* первая строка */
}

🔍 Разбор:

  • ::before { content: "«"; } — добавляет кавычку перед текстом
  • content: "" — пустой контент (для чисто декоративных элементов)
  • ::placeholder — стилизация текста-подсказки в input
  • ::selection — цвет фона/текста при выделении мышью
  • ::first-letter — буквица (первая буква параграфа)

💡 Полезный совет:

::before и ::after с content: "" — это идеальный способ добавить декоративные линии, иконки, фон, не захламляя HTML. А с content: attr(data-tooltip) можно даже сделать тултип на чистом CSS!

⚠️ Типичная ошибка:

Забыть content у ::before/::after. Без этого свойства псевдоэлемент НЕ ПОЯВИТСЯ. Даже если контент пустой — пиши content: "".

✅ Итоги урока:

  • ::before / ::after — виртуальные элементы
  • content — ОБЯЗАТЕЛЬНО для них
  • ::placeholder — стиль подсказок
  • ::selection — цвет выделения
  • ::first-letter / ::first-line — буквица и первая строка

🧠 Самостоятельная работа:

  1. Добавь кавычки-ёлочки вокруг цитаты с помощью ::before и ::after.
  2. Создай стильную разделительную линию с помощью ::before с пустым контентом.
  3. Сделай красивую буквицу в первом параграфе статьи.

🤖 Вопрос к размышлению:

Почему псевдоэлементы не видны в HTML-коде страницы, но видны в DevTools?

🎉 Бонус:

Псевдоэлементы — это как невидимые помощники. Они делают красоту, не загрязняя HTML. Ты начинаешь мыслить чисто и элегантно! 🎭
