🎬 Анимации и переходы: transition, transform, @keyframes

🎯 Цель урока

Научиться создавать плавные переходы, двигать и трансформировать элементы, а также делать анимации с помощью ключевых кадров.

📚 Теория

  1. transition — плавный переход между состояниями:
    .button {
    background-color: blue;
    transition: background-color 0.3s ease;
    /* свойство длительность функция-сглаживания */
}
.button:hover {
    background-color: red;  /* изменится плавно за 0.3с */
}
    Функции сглаживания: ease, linear, ease-in, ease-out.
  2. transform — трансформации:
    .card:hover {
    transform: scale(1.05);         /* увеличить на 5% */
    transform: rotate(5deg);        /* повернуть */
    transform: translateY(-10px);   /* сдвинуть вверх */
    transform: skew(5deg);          /* наклонить */
    /* комбо: */
    transform: scale(1.1) rotate(3deg);
}
  3. @keyframes — ключевые кадры (анимации) 🔥:
    @keyframes slideIn {
    from {
        transform: translateX(-100%);
        opacity: 0;
    }
    to {
        transform: translateX(0);
        opacity: 1;
    }
}
/* или с процентами: */
@keyframes pulse {
    0%   { transform: scale(1); }
    50%  { transform: scale(1.1); }
    100% { transform: scale(1); }
}
.element {
    animation: pulse 2s infinite;
    /* имя длительность повторение */
}

🔍 Разбор:

  • transition: свойство 0.3s — что анимируем и как долго
  • transform: scale(1.2) — масштаб (1 = 100%)
  • translateY(-10px) — двигаем по Y (вверх — минус)
  • @keyframes — определяем кадры анимации
  • animation: имя 2s infinite — применяем анимацию

💡 Полезный совет:

Всегда добавляй transition к элементу, а не только к :hover. Тогда и появление, и исчезновение эффекта будут плавными!

Анимации делай лёгкими и быстрыми (200-400мс). Всё, что дольше — раздражает пользователя.

⚠️ Типичная ошибка:

Анимировать свойства, которые плохо поддаются анимации (height, display). Это дёргается! Используй transform и opacity — они работают на GPU и всегда плавные.

✅ Итоги урока:

  • transition — плавный переход
  • transform — сдвиг, поворот, масштаб
  • @keyframes — ключевые кадры
  • animation — применение анимации
  • ease, linear — сглаживание

🧠 Самостоятельная работа:

  1. Создай кнопку, которая плавно меняет цвет фона при наведении.
  2. Создай карточку, которая при наведении поднимается вверх (translateY(-10px)) и немного увеличивается.
  3. Создай анимацию появления элемента (слева въезжает + плавно проявляется).
