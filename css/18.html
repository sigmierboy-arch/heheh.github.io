📱 Адаптивная вёрстка: медиа-запросы (@media), mobile-first

🎯 Цель урока

Понять принципы адаптивной вёрстки и научиться использовать медиа-запросы для разных размеров экрана.

📚 Теория

Адаптивная вёрстка (Responsive Web Design) — это подход, при котором сайт подстраивается под размер экрана.

Медиа-запросы @media:

/* Стили для всех устройств (mobile-first) */
.container {
    display: block;
}

/* Для планшетов и больше (≥768px) */
@media (min-width: 768px) {
    .container {
        display: flex;
        gap: 20px;
    }
}

/* Для десктопов (≥1024px) */
@media (min-width: 1024px) {
    .container {
        max-width: 1200px;
        margin: 0 auto;
    }
}

Mobile-first подход 🔥:
Пишем стили сначала для мобильных, а потом расширяем для больших экранов:

/* Базовые стили = мобильные */
.card {
    width: 100%;
}

/* Планшет */
@media (min-width: 768px) {
    .card {
        width: 48%;
    }
}

/* Десктоп */
@media (min-width: 1024px) {
    .card {
        width: 31%;
    }
}

Типичные брейкпоинты:

  • 320-480px — маленькие телефоны
  • 480-768px — большие телефоны / маленькие планшеты
  • 768-1024px — планшеты
  • 1024-1200px+ — десктопы

Медиа-запросы могут проверять не только ширину:

@media (orientation: landscape) { ... }  /* горизонтальная */
@media (prefers-color-scheme: dark) { ... } /* тёмная тема */
@media (max-width: 600px) { ... }  /* до 600px */
@media print { ... }  /* стили для печати */

🔍 Разбор:

  • @media (min-width: 768px) — сработает, если ширина ≥768px
  • Mobile-first: базовые стили = маленькие экраны
  • min-width — «от этого размера и больше» (mobile-first)
  • max-width — «до этого размера» (desktop-first, реже)
  • Брейкпоинты добавляем туда, где вёрстка ломается

💡 Полезный совет:

Всегда используй mobile-first и min-width. Так код читается логичнее: базовые стили → расширения для больших экранов. И mobile-first заставляет думать о самом важном контенте в первую очередь!

А ещё — тестируй на реальных устройствах, а не только в DevTools.

⚠️ Типичная ошибка:

Забыть мета-тег <meta name="viewport" content="width=device-width, initial-scale=1.0"> в HTML. Без него мобильные браузеры будут масштабировать страницу, и медиа-запросы не сработают!

✅ Итоги урока:

  • @media — медиа-запросы
  • Mobile-first — начинаем с мобильных
  • min-width — от размера и больше
  • Брейкпоинты: 768px, 1024px
  • viewport мета-тег обязателен

🧠 Самостоятельная работа:

  1. Создай страницу с тремя карточками. На мобильном — в столбик, на планшете — в 2 колонки, на десктопе — в 3.
  2. Добавь @media (prefers-color-scheme: dark) и стилизуй тёмную тему для своего сайта.
  3. Проверь сайт в DevTools (режим эмуляции устройств) и на реальном телефоне.
