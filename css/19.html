⚡ Переменные CSS (Custom Properties) и функция calc()

🎯 Цель урока

Научиться использовать CSS-переменные для чистого кода и функцию calc() для вычислений.

📚 Теория

CSS-переменные (Custom Properties):
Позволяют хранить значения (цвета, размеры, шрифты) и переиспользовать их.

:root {
    --primary-color: #3498db;
    --secondary-color: #2ecc71;
    --text-color: #333;
    --spacing-unit: 16px;
    --border-radius: 8px;
}

.button {
    background-color: var(--primary-color);
    padding: var(--spacing-unit);
    border-radius: var(--border-radius);
}
.card {
    color: var(--text-color);
    padding: calc(var(--spacing-unit) * 2);
}

Преимущества переменных:

  1. Изменил в :root — обновилось везде
  2. Можно менять через JavaScript
  3. Работают в медиа-запросах:
@media (prefers-color-scheme: dark) {
    :root {
        --bg-color: #222;
        --text-color: #eee;
    }
}

Функция calc():
Математика прямо в CSS!

.sidebar {
    width: calc(100% - 300px);  /* вся ширина минус 300px */
}
.column {
    width: calc((100% - 40px) / 3);  /* три колонки с gap 20px */
}
.heading {
    font-size: calc(1rem + 1vw);  /* адаптивный шрифт! */
}

🔍 Разбор:

  • :root — псевдокласс, означающий корень документа (обычно <html>)
  • --имя: значение — объявление переменной (всегда с двумя дефисами)
  • var(--имя) — использование переменной
  • calc(выражение) — математическое вычисление
  • calc(100% - 300px) — динамический расчёт ширины

💡 Полезный совет:

Создай систему переменных для всего проекта: цвета, шрифты, отступы, тени, скругления. Это называется «дизайн-токены». Потом легко менять тему или адаптировать под бренд!

А calc() + переменные = магия: calc(var(--spacing) * 2).

⚠️ Типичная ошибка:

Забыть пробелы вокруг операторов в calc(). calc(100%-20px) — ОШИБКА. Правильно: calc(100% - 20px).

✅ Итоги урока:

  • --имя: значение — объявление переменной
  • :root — глобальная область видимости
  • var(--имя) — использование
  • calc() — математические выражения
  • Переменные + медиа-запросы = тёмная тема

🧠 Самостоятельная работа:

  1. Создай набор переменных для цветов и шрифтов в :root. Используй их во всех стилях.
  2. Создай адаптивный шрифт с помощью calc(): font-size: calc(16px + 0.5vw).
  3. Реализуй тёмную тему через медиа-запрос и переменные.

🤖 Вопрос к размышлению:

Чем CSS-переменные лучше, чем переменные в препроцессорах (SASS/LESS)?
