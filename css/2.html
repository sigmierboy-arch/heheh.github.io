🎯 Селекторы: выбираем элементы как снайпер

🎯 Цель урока

Научиться выбирать HTML-элементы для стилизации с помощью разных типов CSS-селекторов.

📚 Теория

Селектор — это способ указать браузеру, к каким элементам применить стили.

Основные типы селекторов:

  1. Селектор по тегу — выбирает все элементы этого типа:
    h1 {
    color: navy;
}
  2. Селектор по классу (начинается с точки) — можно использовать многократно:
    .highlight {
    background-color: yellow;
}
  3. Селектор по id (начинается с решётки) — уникальный элемент:
    #main-title {
    font-size: 32px;
}
  4. Универсальный селектор * — выбирает ВСЁ:
    * {
    margin: 0;
    padding: 0;
}
  5. Групповой селектор — стили для нескольких элементов сразу:
    h1, h2, h3 {
    font-family: Arial, sans-serif;
}
  6. Вложенный селектор — элементы внутри других:
    article p {
    line-height: 1.6;
}
    (Все <p> внутри <article>)

🔍 Разбор селекторов:

  • h1 — по тегу (все h1)
  • .класс — точка = класс (много элементов)
  • #id — решётка = уникальный id (один элемент)
  • * — звёздочка = всё на странице
  • div p — пробел = вложенность (все p внутри div)

💡 Полезный совет:

Старайся использовать селекторы по классу. У них оптимальная специфичность, и код легко переиспользовать. Избегай #id для стилей (оставь их для JavaScript и якорей).

⚠️ Типичная ошибка:

Путать точку и решётку. .header — это класс, #header — это id. Легко перепутать, а ошибку искать долго!

✅ Итоги урока:

  • Селектор по тегу: p { }
  • По классу: .class { }
  • По id: #id { }
  • Универсальный: * { }
  • Групповой: h1, h2 { }
  • Вложенный: parent child { }

🧠 Самостоятельная работа:

  1. Создай HTML с 5 элементами разных типов (h1, h2, p, div, span). Стилизуй их с помощью селекторов по тегу.
  2. Добавь класс .accent к двум разным элементам. Задай оранжевый цвет через селектор класса.
  3. Создай <section>, внутри которого несколько <p>. Используй вложенный селектор section p.

🤖 Вопрос к размышлению:

Почему для стилей рекомендуют классы, а не id? В чём минусы id для стилизации?

🎉 Бонус:

Ты научился точно целиться в элементы! Селекторы — это твой прицел. Чем точнее прицел, тем чище код. 🔫
