🏆 Итоговый проект «Лендинг с нуля»

🎯 Цель урока

Консолидировать все знания и создать завершённый адаптивный лендинг с использованием Flexbox/Grid, анимаций и переменных.

📚 Техническое задание (ТЗ) на проект

Создай файл index.html и style.css. Лендинг должен содержать:

  1. Шапка (header):
    • Логотип + навигация
    • position: sticky
    • При прокрутке добавляется тень
  2. Hero-секция (первый экран):
    • Крупный заголовок + подзаголовок + кнопка
    • Фоновый градиент или картинка
    • Кнопка с анимацией при наведении
  3. Секция «Преимущества»:
    • 3-4 карточки
    • На мобильном — в столбик, на десктопе — в ряд (Flexbox)
    • Карточки с тенью и скруглениями
    • Анимация подъёма при наведении
  4. Секция «О нас»:
    • Двухколоночный макет (Grid)
    • Картинка слева, текст справа
    • На мобильном — в одну колонку
  5. Форма обратной связи:
    • Поля: имя, email, сообщение
    • Стилизованные input'ы и кнопка
    • Валидация через псевдокласс :invalid
  6. Подвал (footer):
    • Копирайт, ссылки, тёмный фон
  7. Тёмная тема:
    • Поддержка prefers-color-scheme: dark

Технические требования:

  • Все цвета и отступы — через CSS-переменные
  • Использовать box-sizing: border-box
  • Mobile-first адаптив (минимум 2 брейкпоинта)
  • Валидный CSS (проверить в валидаторе)

🔍 Структура проекта:

  1. :root — все переменные
  2. Базовые стили (mobile)
  3. @media (min-width: 768px) — планшеты
  4. @media (min-width: 1024px) — десктопы
  5. @media (prefers-color-scheme: dark) — тёмная тема

💡 Полезный совет:

Начни с HTML-структуры. Потом базовые стили. Потом Flexbox/Grid для раскладки. Потом декоративные стили (тени, скругления). Потом анимации. В самом конце — адаптив и тёмная тема. Иди слоями!

⚠️ Напоминание:

Не забывай: viewport мета-тег, box-sizing: border-box, переменные в :root, мобильные стили как базовые!
