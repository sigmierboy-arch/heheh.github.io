🌈 Цвета в CSS: раскрашиваем мир

🎯 Цель урока

Научиться задавать цвета в CSS всеми возможными способами и управлять цветом текста и фона.

📚 Теория

Цвет в CSS можно задать несколькими способами:

  1. Именованные цвета — просто английское название:
    color: red;
color: dodgerblue;
color: tomato;
  2. HEX-код — решётка + 6 символов (0-9, A-F):
    color: #FF0000;   /* Красный */
color: #00FF00;   /* Зелёный */
color: #0000FF;   /* Синий */
color: #333;      /* Сокращённо: #333 = #333333 */
  3. RGB — Red, Green, Blue (0-255):
    color: rgb(255, 0, 0);       /* Красный */
color: rgb(0, 128, 0);       /* Тёмно-зелёный */
  4. RGBA — RGB + Альфа-канал (прозрачность 0-1):
    color: rgba(0, 0, 0, 0.5);   /* Полупрозрачный чёрный */
background-color: rgba(255, 0, 0, 0.3);
  5. HSL / HSLA — Hue, Saturation, Lightness:
    color: hsl(0, 100%, 50%);     /* Красный */
color: hsla(240, 100%, 50%, 0.7);
Основные свойства:
  • color — цвет текста
  • background-color — цвет фона элемента

🔍 Разбор:

  • color — красит ТЕКСТ
  • background-color — красит ФОН позади текста
  • rgba(0,0,0,0.5) — последнее число (0.5) = 50% прозрачности
  • HEX #FF00AA: FF=красный, 00=зелёный, AA=синий

💡 Полезный совет:

Используй HEX для сплошных цветов и RGBA, когда нужна прозрачность. А чтобы быстро подобрать цвет — гугли «color picker» или используй DevTools (F12).

⚠️ Типичная ошибка:

Забыть решётку # в HEX. color: FF0000; не сработает. Всегда: color: #FF0000;

✅ Итоги урока:

  • Именованные цвета: red, blue
  • HEX: #FF0000, #333
  • RGB/RGBA: rgb(255,0,0), rgba(0,0,0,0.5)
  • HSL/HSLA: hsl(0,100%,50%)
  • color — текст, background-color — фон

🧠 Самостоятельная работа:

  1. Создай 5 <div> и раскрась каждый разным способом: именованный, HEX, RGB, RGBA, HSL.
  2. Создай параграф с полупрозрачным красным фоном и чёрным текстом.
  3. Найди в интернете HEX-код своего любимого цвета и используй его для заголовка.

🤖 Вопрос к размышлению:

Зачем нужна прозрачность (RGBA), если можно просто подобрать похожий непрозрачный цвет?
