📏 Размеры и отступы: width, height, margin, padding

🎯 Цель урока

Понять блочную модель CSS и научиться управлять размерами элементов и отступами: width, height, margin, padding, border.

📚 Теория

Блочная модель (CSS Box Model):
Каждый элемент — это прямоугольник, состоящий из слоёв: 

┌─────────────────────────────┐
│         margin              │
│  ┌───────────────────────┐  │
│  │       border          │  │
│  │  ┌─────────────────┐  │  │
│  │  │    padding      │  │  │
│  │  │  ┌───────────┐  │  │  │
│  │  │  │  CONTENT  │  │  │  │
│  │  │  └───────────┘  │  │  │
│  │  └─────────────────┘  │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
Свойства:
  • width / height — размеры СОДЕРЖИМОГО
  • padding — ВНУТРЕННИЙ отступ (от контента до границы)
  • border — ГРАНИЦА элемента
  • margin — ВНЕШНИЙ отступ (от границы до соседей)
div {
    width: 300px;
    height: 200px;
    padding: 20px;
    border: 2px solid black;
    margin: 30px;
}

🔍 Разбор:

  • width: 300px — ширина контента 300 пикселей
  • padding: 20px — воздух ВНУТРИ (от текста до рамки)
  • border: 2px solid black — рамка: толщина, стиль, цвет
  • margin: 30px — воздух СНАРУЖИ (от рамки до других элементов)

Сокращённая запись: 

margin: 10px 20px 30px 40px;
/* верх право низ лево (по часовой) */

💡 Полезный совет:

Запомни порядок для margin/padding: TRouBLe — Top, Right, Bottom, Left (как «трабл» — проблема). Или по часовой стрелке начиная сверху.

⚠️ Типичная ошибка:

Думать, что width: 300px — это полная ширина элемента. На самом деле полная ширина = width + padding-left + padding-right + border-left + border-right. Это называется box-sizing (о нём позже).

✅ Итоги урока:

  • width/height — размеры контента
  • padding — внутренний отступ
  • border — граница
  • margin — внешний отступ
  • Блочная модель = content + padding + border + margin

🧠 Самостоятельная работа:

  1. Создай три <div> с разными padding. Внутри каждого — текст. Посмотри, как padding влияет на положение текста.
  2. Создай два блока и задай им margin-bottom: 30px. Посмотри на расстояние между ними.
  3. Нарисуй на бумаге блочную модель и подпиши все 4 слоя для элемента с width: 200px, padding: 15px, border: 3px, margin: 25px.

🤖 Вопрос к размышлению:

Почему margin двух соседних элементов иногда «схлопывается», а padding — никогда?

🎉 Бонус:

Блочная модель — это азбука CSS. Понимая её, ты понимаешь 50% всей вёрстки. Ты красавчик! 📦
