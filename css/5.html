✍️ Шрифты: font-family, font-size, font-weight, line-height

🎯 Цель урока

Научиться управлять шрифтами: выбирать гарнитуру, задавать размер, жирность, курсив и межстрочный интервал.

📚 Теория

Основные свойства шрифтов:

  1. font-family — семейство шрифта. Всегда указывай запасные варианты!
    body {
    font-family: 'Roboto', Arial, sans-serif;
}
  2. font-size — размер шрифта:
    p {
    font-size: 16px;    /* пиксели */
    font-size: 1.2em;   /* относительно родителя */
    font-size: 1.5rem;  /* относительно корня (html) */
}
  3. font-weight — жирность:
    font-weight: normal;   /* 400 */
font-weight: bold;     /* 700 */
font-weight: 300;      /* Light */
font-weight: 900;      /* Black */
  4. font-style — начертание:
    font-style: italic;
font-style: normal;
  5. line-height — межстрочный интервал:
    line-height: 1.5;  /* 150% от размера шрифта — золотой стандарт */
  6. text-align — выравнивание:
    text-align: center;
text-align: justify;
text-align: right;

🔍 Разбор:

  1. font-family: 'Roboto', Arial, sans-serif; — если Roboto нет, берём Arial, если и его нет — любой без засечек
  2. font-size: 16px — абсолютный размер
  3. font-size: 1.5rem — относительный (1.5 × базовый размер html)
  4. line-height: 1.5 — без единиц! Умножается на font-size

💡 Полезный совет:

Используй rem для размеров шрифта! В отличие от px, пользователь может масштабировать текст в браузере. А line-height: 1.5 — это комфортное чтение.

⚠️ Типичная ошибка:

Забыть кавычки у названия шрифта из двух слов. font-family: Times New Roman; — ОШИБКА! Правильно: font-family: 'Times New Roman', serif;

✅ Итоги урока:

  • font-family — гарнитура (с запасными)
  • font-size — размер (px, em, rem)
  • font-weight — жирность (100-900)
  • font-style — курсив
  • line-height — межстрочный интервал
  • text-align — выравнивание

🧠 Самостоятельная работа:

  1. Подключи Google Fonts (выбери любой шрифт) и примени его к заголовкам.
  2. Создай статью с заголовком и текстом. Задай: заголовок — жирный 32px, текст — 16px с line-height: 1.6.
  3. Поэкспериментируй с rem: задай html { font-size: 20px; } и используй 1.5rem для параграфов.
