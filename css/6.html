🖼️ Фоны: background-color, background-image, background-size

🎯 Цель урока

Научиться настраивать фон элемента: заливать цветом, добавлять картинки, управлять их размером и позицией, создавать градиенты.

📚 Теория

Основные свойства фона:

  1. background-color — цвет фона (уже знакомы)
  2. background-image — картинка фона:
    body {
    background-image: url('bg.jpg');
}
  3. background-repeat — повторение:
    background-repeat: no-repeat;  /* не повторять */
background-repeat: repeat-x;   /* только по горизонтали */
  4. background-position — позиция:
    background-position: center;
background-position: top right;
background-position: 50% 50%;
  5. background-size — размер:
    background-size: cover;   /* заполнить весь блок */
background-size: contain;  /* поместить целиком */
background-size: 100px 200px;
  6. background-attachment — прокрутка:
    background-attachment: fixed;  /* параллакс-эффект! */
Градиенты — это тоже background-image: 
background-image: linear-gradient(to right, red, blue);
background-image: radial-gradient(circle, yellow, green);

🔍 Разбор:

  • url('bg.jpg') — путь к картинке
  • no-repeat — без плитки
  • cover — масштабирует, чтобы заполнить всё (может обрезать)
  • contain — масштабирует, чтобы поместилась целиком (могут быть поля)
  • linear-gradient(направление, цвет1, цвет2) — плавный переход

💡 Полезный совет:

Используй сокращённое свойство background: 

background: #f0f0f0 url('bg.jpg') no-repeat center/cover;
Порядок: цвет, картинка, повтор, позиция/размер.

⚠️ Типичная ошибка:

Забыть кавычки у url(). Хотя без кавычек иногда работает, лучше всегда писать url('image.jpg') — это безопаснее.

✅ Итоги урока:

  • background-color — цвет
  • background-image — картинка или градиент
  • background-repeat — повторение
  • background-size: cover/contain
  • background-position — позиция
  • linear-gradient() — градиенты

🧠 Самостоятельная работа:

  1. Создай блок <div> 400×300px с фоновой картинкой (любая из интернета). Используй background-size: cover.
  2. Сделай параграф с полупрозрачным фоновым цветом и фоновой картинкой, которая не перекрывает текст.
  3. Создай блок с градиентом от жёлтого к оранжевому слева направо.
