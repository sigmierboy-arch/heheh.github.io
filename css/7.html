Вернуться

📦 Границы и тени: border, border-radius, box-shadow, text-shadow

🎯 Цель урока

Научиться создавать рамки, скруглять углы элементов и добавлять тени для объёма и красоты.

📚 Теория

  1. border — рамка (толщина, стиль, цвет):
    div {
    border: 2px solid #333;
    /* толщина стиль цвет */
    border: 3px dashed red;
    border: 1px dotted blue;
}
    Стили рамок: solid (сплошная), dashed (пунктир), dotted (точки), double (двойная), none (без рамки).
  2. border-radius — скругление углов:
    div {
    border-radius: 10px;           /* все углы */
    border-radius: 50%;            /* идеальный круг! */
    border-radius: 10px 20px 30px 40px; /* каждый угол отдельно */
}
  3. box-shadow — тень элемента:
    div {
    box-shadow: 5px 5px 10px rgba(0,0,0,0.3);
    /* сдвигX сдвигY размытие цвет */
    box-shadow: 0 4px 6px rgba(0,0,0,0.1); /* популярная тень */
}
  4. text-shadow — тень текста:
    h1 {
    text-shadow: 2px 2px 4px rgba(0,0,0,0.5);
}

🔍 Разбор:

  • border: 2px solid #333; — рамка 2px, сплошная, тёмно-серая
  • border-radius: 50% — овал/круг (если width=height — идеальный круг)
  • box-shadow: X Y размытие цвет — положительный X = тень справа, положительный Y = снизу
  • rgba(0,0,0,0.3) — чёрная тень с 30% непрозрачности

💡 Полезный совет:

Используй box-shadow: 0 4px 6px rgba(0,0,0,0.1) для карточек. Это даёт лёгкий, современный эффект приподнятости. Тень без сдвига, с размытием — и элемент «всплывает»!

⚠️ Типичная ошибка:

Забыть solid (стиль) в border. border: 2px red; не сработает. Нужно: border: 2px solid red;

✅ Итоги урока:

  • border — рамка (толщина, стиль, цвет)
  • border-radius — скругление углов (вплоть до круга)
  • box-shadow — тень блока
  • text-shadow — тень текста

🧠 Самостоятельная работа:

  1. Создай 4 <div> с разными стилями рамок: solid, dashed, dotted, double.
  2. Создай аватар (квадратную картинку) и скругли её до круга с помощью border-radius: 50%.
  3. Создай «приподнятую» карточку с тенью и скруглёнными углами.

🤖 Вопрос к размышлению:

Почему тень делает элемент визуально «приподнятым»? Как это работает с точки зрения восприятия?

🎉 Бонус:

Тени и скругления — это то, что превращает плоский дизайн в объёмный. Твои сайты начинают выглядеть как настоящие приложения! 🎴
