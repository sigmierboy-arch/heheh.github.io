📐 Свойство display: block, inline, inline-block, none

🎯 Цель урока

Разобраться с типами отображения элементов (display) и научиться менять их поведение: блочный, строчный, строчно-блочный, скрытый.

📚 Теория

display — главное свойство, определяющее поведение элемента в потоке.

  1. display: block (блочный)
    • Занимает ВСЮ доступную ширину
    • Начинается с новой строки
    • <div>, <p>, <h1>-<h6>, <section>
  2. display: inline (строчный)
    • Занимает место ПО СОДЕРЖИМОМУ
    • НЕ начинает новую строку
    • <span>, <a>, <strong>
    • НЕЛЬЗЯ задать width/height!
  3. display: inline-block (строчно-блочный) 🔥
    • Как inline (в строку), НО можно задавать width и height!
    • Идеально для карточек в ряд
  4. display: none (скрытый)
    • Элемент ИСЧЕЗАЕТ из потока (как будто его нет)
    • Отличается от visibility: hidden (место остаётся)
.card {
    display: inline-block;
    width: 250px;
    height: 300px;
    margin: 10px;
}

🔍 Разбор кода по косточкам:

  1. block — «я — кирпич, занимаю весь ряд»
  2. inline — «я — слово в предложении»
  3. inline-block — «я — кирпичик в строку, но с размерами»
  4. none — «меня нет» (место не занимаю)
  5. visibility: hidden — «я невидим, но место моё»

💡 Полезный совет:

Если нужно выстроить карточки в ряд, используй display: inline-block (или Flexbox, о нём позже). А чтобы убрать пробелы между inline-block элементами — задай родителю font-size: 0 (а детям верни обратно).

⚠️ Типичная ошибка:

Пытаться задать width и height строчному элементу (inline). span { width: 100px; } — НЕ РАБОТАЕТ! Сначала смени display на inline-block или block.

✅ Итоги урока:

  • display: block — блочный (вся ширина, с новой строки)
  • display: inline — строчный (по содержимому)
  • display: inline-block — строчный + можно размеры
  • display: none — скрыть (место исчезает)

🧠 Самостоятельная работа:

  1. Создай три <div>, задай им display: inline-block и убедись, что они встали в один ряд.
  2. Попробуй задать ширину и высоту <span>. Потом смени ему display: inline-block и сравни.
  3. Создай блок с display: none и такой же с visibility: hidden. Посмотри разницу в расположении остальных элементов.

🤖 Вопрос к размышлению:

Где в реальной жизни пригодится visibility: hidden вместо display: none?

🎉 Бонус:

Понимание display — это как выучить ноты в музыке. Дальше пойдут аккорды (Flexbox) и симфонии (Grid)! 🎵
