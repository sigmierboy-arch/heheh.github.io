📏 Размеры правильно: box-sizing: border-box

🎯 Цель урока

Понять разницу между content-box и border-box и навсегда решить проблему расчёта размеров.

📚 Теория

Проблема:
По умолчанию (box-sizing: content-box) ширина width: 300px относится ТОЛЬКО к контенту. Padding и border добавляются СВЕРХУ: 

div {
    width: 300px;
    padding: 20px;
    border: 5px solid black;
}
/* Реальная ширина = 300 + 20*2 + 5*2 = 350px! */
Решение: box-sizing: border-box 🔥
С этим свойством width включает и padding, и border: 
* {
    box-sizing: border-box;
}
/* Реальная ширина = ровно 300px, padding и border внутри */
Это свойство настолько важно, что его добавляют в КАЖДЫЙ проект: 
*, *::before, *::after {
    box-sizing: border-box;
}

🔍 Разбор кода по косточкам:

  1. content-box — по умолчанию, width = только контент
  2. border-box — width = контент + padding + border
  3. С border-box ты говоришь браузеру: «Вот ширина, вмести всё внутрь»
  4. Универсальный селектор * применяет это ко ВСЕМ элементам

💡 Полезный совет:

Всегда начинай CSS-файл с этого заклинания: 

*, *::before, *::after {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}
Это сбросит все встроенные отступы и включит удобный режим размеров. База любого проекта!

⚠️ Типичная ошибка:

Забыть про box-sizing и мучиться: «Почему два блока по 50% не влезают в строку?». Потому что padding добавляется! С border-box такой проблемы нет.

✅ Итоги урока:

  • content-box — width только контента (по умолчанию)
  • border-box — width включает padding и border
  • box-sizing: border-box — must-have для любого проекта
  • Сбрасывай отступы и ставь border-box в начале CSS

🧠 Самостоятельная работа:

  1. Создай два блока шириной 50% с padding: 20px. Без border-box они упадут в столбик. Добавь border-box — встанут в ряд!
  2. Создай CSS-файл, который ты будешь использовать во всех проектах. Первым правилом поставь box-sizing: border-box.
  3. Нарисуй на бумаге два одинаковых блока: один с content-box, другой с border-box. Покажи, как распределятся padding и border.

🤖 Вопрос к размышлению:

Почему разработчики CSS сделали content-box по умолчанию, а не более удобный border-box?

🎉 Бонус:

Ты только что избавился от головной боли с размерами на всю жизнь! border-box — это суперсила. Теперь вёрстка будет предсказуемой. 💪
