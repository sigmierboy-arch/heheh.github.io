🏷️ Атрибуты class и id: даём имена и фамилии

🎯 Цель урока

Понять разницу между атрибутами class (для группы) и id (для уникального элемента).

📚 Теория

  1. id — Уникальный идентификатор
    Как номер паспорта. На странице — ТОЛЬКО ОДИН элемент с конкретным id. 
    <header id="main-header">
    <h1>Мой сайт</h1>
</header>
  2. class — Класс (группа)
    Как фамилия. Можно присвоить многим элементам. Один элемент может иметь несколько классов через пробел. 
    <p class="important-text highlighted">Важный и подсвеченный текст</p>
<p class="important-text">Просто важный текст</p>
<p>Обычный текст</p>

🔍 Разбор кода по косточкам:

  • id="main-header" — уникальный идентификатор
  • class="important-text highlighted" — два класса у одного элемента
  • Несколько классов пишутся через пробел

💡 Полезный совет:

Имена должны описывать СМЫСЛ, а не внешний вид.
Плохо: class="red-text", class="left-column"
Хорошо: class="error-message", class="sidebar"

⚠️ Типичная ошибка:

Дублировать одинаковые id на странице. Для группы всегда используй class!

✅ Итоги урока:

  • id — уникальное имя (раз на странице)
  • class — имя для группы (много раз)
  • Имена должны быть осмысленными

🧠 Самостоятельная работа:

  1. Добавь одинаковый class="card" всем карточкам.

  2. Шапке добавь id="header", подвалу — id="footer".

  3. Одной карточке добавь дополнительный класс class="card special".

🤖 Вопрос к размышлению:

Как бы ты назвал классы для формы подписки: id="subscribe-form" или id="blue-block"? Почему?
