📊 Таблицы — наводим порядок в данных

🎯 Цель урока

Научиться создавать HTML-таблицы для отображения табличных данных с правильной семантической структурой.

📚 Теория

Таблица строится послойно:

  1. <table> — внешний контейнер
  2. <tr> (Table Row) — СТРОКА
  3. <th> (Table Header) — ячейка-ЗАГОЛОВОК
  4. <td> (Table Data) — ячейка с ДАННЫМИ
<table>
    <tr>
        <th>Имя</th>
        <th>Возраст</th>
    </tr>
    <tr>
        <td>Анна</td>
        <td>28</td>
    </tr>
</table>
Семантика для крутых таблиц:
  • <thead> — шапка
  • <tbody> — тело
  • <tfoot> — подвал (итоги)

🔍 Разбор кода по косточкам:

  • <tr> — строка
  • <th> — жирный заголовок по центру
  • <td> — обычные данные
  • colspan="2" — объединить 2 колонки
  • rowspan="2" — объединить 2 строки

💡 Полезный совет:

<td colspan="2">Итого: 2 товара</td>
Ячейка растянется на 2 колонки. Магия!

⚠️ Типичная ошибка:

Использовать таблицы для вёрстки макета всей страницы! Таблицы — ТОЛЬКО для табличных данных. Для макетов — CSS Grid/Flexbox.

✅ Итоги урока:

  • <table>, <tr>, <td>, <th>
  • <thead>, <tbody>, <tfoot>
  • colspan и rowspawn для объединения

🧠 Самостоятельная работа:

  1. Создай расписание уроков: «№ урока», «Время», «Предмет».

  2. Создай таблицу-калькулятор калорий с <thead>, <tbody>, <tfoot>. В подвале объедини ячейки через colspan.

  3. Нарисуй таблицу 3x3 на бумаге и попробуй объединить центральную ячейку со следующей.
