📬 Формы — начинаем диалог с пользователем

🎯 Цель урока

Понять структуру HTML-формы и научиться создавать простые поля ввода и кнопки.

📚 Теория

Всё начинается с <form>. Внутри — поля ввода и кнопки.

Базовые элементы: 

<form action="/search" method="get">
    <label for="search-query">Поиск:</label>
    <input type="text" id="search-query" name="query" placeholder="Введите запрос...">
    <button type="submit">Искать 🔍</button>
</form>
Другие типы input:
  • type="email" — поле для почты
  • type="passwprd" — скрытые символы
  • type="number" — только цифры
  • type="checkbox" — галочка (много)
  • type="radio" — радио-кнопка (одна из группы, одинаковый name!)

🔍 Разбор кода по косточкам:

  • <form> — контейнер формы
  • <label for="id"> — подпись к полю, клик по ней = фокус на поле
  • <input type="..."> — поле ввода
  • name="..." — имя переменной для отправки на сервер
  • placeholder="..." — подсказка внутри поля
  • <button type="submit"> — кнопка отправки

💡 Полезный совет:

Всегда связывай <label> и <input>. Маленькая область клика на «галочку» расширяется до текста — пользователи скажут спасибо!

⚠️ Типичная ошибка:

Забыть name у инпутов. Без него данные не отправятся на сервер! И радио-кнопкам в одной группе — одинаковый name.

✅ Итоги урока:

  • <form> — контейнер
  • <input> — основной элемент, тип через type
  • <label> — подпись, улучшает UX
  • type="submit" — отправка формы

🧠 Самостоятельная работа:

  1. Создай форму «Связаться с нами»: Имя, Email, кнопка «Отправить».

  2. Создай форму регистрации: Логин, Пароль, Возраст.

  3. Создай опрос «Любимый цвет» с тремя радио-кнопками и кнопкой «Голосовать».

🤖 Вопрос к размышлению:

Почему у группы радио-кнопок должно быть одинаковое name?

🎉 Бонус:

Формы превращают сайт из «витрины» в настоящее приложение. Ты на шаг ближе к веб-сервисам! 🚀
