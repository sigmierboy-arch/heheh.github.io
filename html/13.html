📎 Продвинутые элементы форм: select, textarea, file

🎯 Цель урока

Изучить теги <textarea>, <select> с <option>, и тип file для создания многофункциональных форм.

📚 Теория

  1. Выпадающий список <select>
    <label for="country">Страна:</label>
<select id="country" name="country">
    <option value="">-- Выберите --</option>
    <option value="ru">Россия</option>
    <option value="us">США</option>
</select>
  2. Многострочный текст <textarea>
    <label for="comment">Комментарий:</label>
<textarea id="comment" name="comment" rows="5" cols="40" placeholder="Ваше мнение..."></textarea>
  3. Загрузка файла
    <input type="file" id="avatar" name="avatar" accept="image/png, image/jpeg">
  4. Группировка: <fieldset> и <legend>
    <fieldset>
    <legend>Личные данные</legend>
    <!-- поля -->
</fieldset>

🔍 Разбор кода по косточкам:

  • <select> — контейнер выпадающего списка
  • <option> — пункт списка, value — что уйдёт на сервер
  • <textarea> — ПАРНЫЙ тег! Не забывай </textarea>
  • accept— ограничение типов файлов
  • <fieldset> + <legend> — группировка полей

💡 Полезный совет:

Используй <fieldset> и <legend> для больших форм — это семантично и красиво!

⚠️ Типичная ошибка:

Оставлять <textarea> открытым как одиночный тег. Это не так! Весь последующий код может оказаться внутри textarea. Всегда закрывай: <textarea></textarea>.

✅ Итоги урока:

  • <select> + <option> = выпадающий список
  • <textarea> (парный!) = многострочный текст
  • type="file" = загрузка файлов
  • <fieldset> + <legend> = группировка

🧠 Самостоятельная работа:

  1. Создай форму обратной связи: Имя, Тема (select), Сообщение (textarea), кнопка.

  2. Создай форму загрузки резюме: Имя, Email, file (accept=".pdf,.doc").

  3. Разбей форму из задания 1 на <fieldset> с легендами.

🤖 Вопрос к размышлению:

Почему <textarea> сделан парным тегом, а не как <input type="textarea">?
