📝 Знакомство с текстом: заголовки и абзацы

🎯 Цель урока

Научиться структурировать текст на веб-странице с помощью заголовков разного уровня и параграфов.

📚 Теория

Представь книгу без оглавления — это была бы каша из букв! HTML даёт нам заголовки и параграфы для структуры.

Заголовки: от <h1> до <h6>
6 уровней заголовков. <h1> — самый главный (один на странице). <h2> — заголовки глав, <h3> — подзаголовки.

<body>
    <h1>Мой блог о кофе ☕</h1>
    <h2>Как выбрать зерна?</h2>
    <p>Текст про выбор зерен...</p>
    <h3>Арабика</h3>
    <p>Информация об арабике...</p>
    <h3>Робуста</h3>
    <p>Информация о робусте...</p>
</body>
Параграфы <p>
Любой сплошной текст должен быть внутри <p>. Браузер автоматически добавит отступы сверху и снизу.

🔍 Разбор кода по косточкам:

  • <h1> — тема всего блога
  • <h2> — крупные разделы
  • <h3> — подразделы внутри
  • Браузер сам сделает <h1> самым крупным, создав визуальную иерархию

💡 Лайфхак:

На одной странице всегда должен быть только один <h1>. Это важно для поисковых систем (SEO).

⚠️ Типичная ошибка:

Использовать заголовки ради размера шрифта. «Нужен крупный текст — вставлю <h1>!» Нет! Для размера есть CSS. Заголовок должен описывать структуру.

✅ Итоги урока:

  • Заголовки (h1-h6) создают структуру
  • <p> для абзацев
  • Один уникальный <h1> на странице
  • Структура важнее внешнего вида

🧠 Самостоятельная работа:

  1. Создай структуру кулинарного рецепта: h1 — название, h2 — «Ингредиенты» и «Приготовление», внутри «Приготовления» — h3 для шагов.

  2. Напиши три параграфа о любимом фильме. Посмотри на отступы между ними.

  3. Намеренно создай два h1 на странице. Визуально всё ок, но семантически — ошибка.

🤖 Вопрос к размышлению:

Зачем поисковой системе знать, какой заголовок на странице самый главный?

🎉 Бонус:

Ты уже не просто пишешь «рыбу», ты учишься мыслить структурно! Это главный навык крутого верстальщика. 🧠
