🎯 Цель урока

Консолидировать все знания и создать завершённую веб-страницу с семантикой, формами, мультимедиа и навигацией.

📚 Техническое задание (ТЗ) на проект

Создай файл portfolio.html со следующими разделами:

  1. Базовая структура: DOCTYPE, html lang="ru", head с meta charset="UTF-8" и title.
  2. Шапка (<header>):
    • Имя/логотип в <h1>
    • Навигация (<h1>) с якорями #about, #skills, #contact
  3. Секция «Обо мне» (<section id="about">):
    • Заголовок <h1>, фото с alt
    • Два параграфа с <strong> и <em>
  4. Секция «Навыки» (<section id="skills">):
    • Маркированный список с вложенностью
  5. Видеовизитка:
    • Вставь YouTube-видео через <iframe> (Поделиться → Встроить)
  6. Форма связи (<section id="contact">):
    • <form> с полями: Имя, Почта, Тема (<select>), Сообщение (<textarea>)
    • <fieldset> с легендой «Контакты»
    • Кнопка отправки
  7. Подвал (<footer>)
    • Копирайт с &copy;
    • Ссылка «Наверх» (якорь)

🔍 Разбор структуры:

  • Это твой итоговый проект — визитная карточка
  • Используй ВСЁ, чему научился: семантику, списки, таблицы (по желанию), формы, мультимедиа, якоря, спецсимволы
  • Проверь код через валидатор W3C
  • Открой DevTools и убедись, что всё чисто

💡 Полезный совет:

Добавь в <head>: <meta charset="UTF-8">. Это гарантирует правильное отображение русских букв, без «кракозябр».

⚠️ Напоминание:

Не забывай закрывать теги, проверять пути, заполнять alt у картинок и name у полей форм!
