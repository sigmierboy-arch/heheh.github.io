📋 Магия наведения порядка: списки

🎯 Цель урока

Научиться создавать маркированные и нумерованные списки в HTML и понимать их разницу.

📚 Теория

В HTML три основных типа списков, разберём два самых нужных.

  1. Маркированный список <ul>
    ul = Unordered List. Порядок не важен. Каждый элемент - <li> (List Item). 
    <h2>Что купить:</h2>
<ul>
    <li>Хлеб 🍞</li>
    <li>Молоко 🥛</li>
    <li>Яблоки 🍏</li>
</ul>
  2. Нумерованный список <ol>
    ul = Ordered List. Порядок ВАЖЕН. Браузер сам нумерует 
    <h2>Как заварить чай</h2>
<ol>
    <li>Вскипятить воду</li>
    <li>Положить заварку</li>
    <li>Залить кипятком</li>
    <li>Ждать 5 мин и наслаждаться 🍵</li>
</ol>

🔍 Разбор кода по косточкам:

  • <ul> — контейнер, говорит: «Сейчас будет список без номера»
  • <ol> — контейнер, говорит: «Список по порядку!»
  • <li> — элемент списка, «кирпичик» для обоих типов

💡 Лайфхак:

Списки можно вкладывать друг в друга! Отлично для многоуровневых меню: 

<ul>
    <li>Фрукты
        <ul>
            <li>Яблоки</li>
            <li>Бананы</li>
        </ul>
    </li>
</ul>

⚠️ Типичная ошибка:

Писать текст внутри <ul> или <ol> без тега <li>. Это грубая ошибка! Любой текст внутри списка ОБЯЗАН быть обёрнут в <li>.

✅ Итоги урока:

  • <ul> — маркированный список
  • <ol> — нумерованный список
  • <li> — элемент списка
  • Списки можно вкладывать

🧠 Самостоятельная работа:

  1. Создай нумерованный список 3 любимых фильмов по порядку.

  2. Создай маркированный список вещей в отпуск.

  3. Создай вложенный список: «Виды транспорта». Внутри «Наземный» — нумерованный подсписок, внутри «Воздушный» — маркированный.

🤖 Вопрос к размышлению:

Какой тип списка лучше для главного меню навигации и почему?
