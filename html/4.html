🔗 Ссылки — порталы в Интернете

🎯 Цель урока

Понять и научиться использовать тег <a> для создания гиперссылок на другие страницы и сайты.

📚 Теория

Ссылка создаётся тегом <a> (anchor — якорь). Главный атрибут — href (Hypertext REFerence), который говорит браузеру КУДА переходить.

Абсолютный путь (на другой сайт): 

<p>Отличный поисковик: 
   <a href="https://www.google.com">Google</a>
</p>
Относительный путь (внутри сайта): 
<p>Узнать больше
   <a href="about.html">обо мне</a>
</p>

🔍 Разбор кода по косточкам:

  • <a> — тег ссылки
  • href="https://..." — GPS-координаты для браузера
  • Текст между тегами — анкор (то, на что можно нажать)

💡 Лайфхак: target="_blank"

Чтобы ссылка открылась в новой вкладке: 

<a href="https://example.com" target="_blank">Откроется в новой вкладке</a>
Это заботливо по отношению к пользователю!

⚠️ Типичная ошибка:

Забыть https:// в абсолютной ссылке. Если написать href="www.google.com", браузер будет искать файл с таким именем в той же папке!

✅ Итоги урока:

  • <a> + href = гиперссылка
  • Абсолютный путь — на другие сайты
  • Относительный путь — внутри сайта
  • target="_blank" — новая вкладка

🧠 Самостоятельная работа:

  1. Создай index.html со списком из 3 любимых сайтов-ссылок (открываются в новой вкладке).

  2. Создай about.html. В index.html сделай ссылку на него. В about.html — ссылку «Назад на главную».

  3. Проверь, что навигация работает туда-сюда. Ты создал мини-сайт! 🚀

🤖 Вопрос к размышлению:

Почему для навигации по своему сайту лучше использовать относительные ссылки, а не абсолютные (file:///C:/Users/...)?

🎉 Бонус:

Ты связал две страницы и научился делать ссылки на весь мир. Ты понял базовый принцип World Wide Web! 🌐
