🎯 Цель урока

Научиться добавлять изображения с помощью тега <img> и его атрибутов.

📚 Теория

<img> — одиночный тег, ему не нужен закрывающий. Два главных атрибута:

  • src (source) — путь к картинке
  • alt (alternative text) — описание
<img src="cat.jpg" alt="Рыжий кот спит на клавиатуре">

🔍 Разбор кода по косточкам:

  • <img> — говорит браузеру: «Здесь картинка»
  • src="cat.jpg" — какой файл загрузить (локальный или URL)
  • alt="..." — описание, если картинка не загрузилась; читается скринридерами

💡 Полезный совет:

Всегда заполняй alt. Это accessibility, помощь при медленном интернете и плюс к SEO.

⚠️ Типичная ошибка:

  • Не заполнять alt
  • Неправильный путь в src
  • Огромные картинки (4000x3000) без оптимизации — сайт будет грузиться вечность

✅ Итоги урока:

  • <img> — одиночный тег
  • src — путь к картинке
  • alt — ОЧЕНЬ важный атрибут
  • Проверяй пути и размеры

🧠 Самостоятельная работа:

  1. Найди мем в интернете, скопируй URL картинки и вставь в src.

  2. Создай мини-галерею из трёх картинок с подписями в <p>.

  3. Намеренно напиши неправильный путь в src и посмотри, что покажет браузер (иконка сломанной картинки + текст из alt).
