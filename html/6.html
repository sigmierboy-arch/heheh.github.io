⚓ Ссылки-картинки и якоря: двойной удар!

🎯 Цель урока

Научиться делать изображения кликабельными ссылками и создавать якоря для навигации внутри страницы.

📚 Теория

  1. Картинка-ссылка
    Помести <img> внутрь <a>: 
    <a href="https://ru.wikipedia.org/wiki/Кот" target="_blank">
    <img src="cat.jpg" alt="Котейка, жми!">
</a>
  2. Якоря (навигация по странице)
    Ставим метку (id) и ссылаемся на неё (href="#имя"): 
    <h2>Оглавление</h2>
<ul>
    <li><a href="#chapter1">Глава 1</a></li>
    <li><a href="#chapter2">Глава 2</a></li>
</ul>

<h2 id="chapter1">Глава 1</h2>
<p>Текст первой главы...</p>

<h2 id="chapter2">Глава 2</h2>
<p>Текст второй главы...</p></pre>

🔍 Разбор кода по косточкам:

  • Картинка внутри <a> = кликабельная картинка
  • id="chapter1" — уникальная метка на элементе
  • href="#chapter1" — решётка говорит: «Ищи id на этой же странице»

💡 Полезный совет:

Не забудь про alt у картинки-ссылки. Если картинка не загрузится, текст из alt станет кликабельной ссылкой!

⚠️ Типичная ошибка:

Написать href="chapter1" без решётки. Браузер будет искать файл chapter1.html, а не элемент на странице.

✅ Итоги урока:

  • Картинка-ссылка: <a><img></a>
  • Якорь: id у цели, href="#id" у ссылки
  • # = «остаёмся на этой же странице»

🧠 Самостоятельная работа:

  1. Сделай картинку-ссылку из галереи на сайт-источник.

  2. Создай длинный документ с меню «Раздел 1, 2, 3». Сделай якоря к каждому разделу.

  3. В конце каждого раздела добавь ссылку «Наверх».
