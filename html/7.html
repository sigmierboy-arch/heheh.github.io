✍️ Фразовые теги: strong, em, u, s, br, hr

🎯 Цель урока

Научиться использовать фразовые теги для смыслового и визуального форматирования текста внутри абзацев.

📚 Теория

Смысловые теги (предпочтительны):

  • <strong> — важность (жирный)
  • <em> — акцент (курсив)
<p>Я <strong>очень</strong> советую книгу <em>«Мастер и Маргарита»</em>. Это <strong><em>обязательно</em></strong>!</p>
Другие полезные теги:
  • <u> — подчёркнутый
  • <s> — зачёркнутый (старая цена)
  • <br> — перенос строки (одиночный)
  • <hr> — горизонтальная линия-разделитель

🔍 Разбор кода по косточкам:

  • <strong> = жирный + смысл важности
  • <em> = курсив + смысл акцента
  • <br> — одиночный тег, только для переноса строки (адреса, стихи)
  • <hr> — тематический разделитель

💡 Полезный совет:

Всегда думай о смысле. Хочешь просто жирный для красоты? Скорее всего, это к CSS. Хочешь показать важность? Используй <strong>.

⚠️ Типичная ошибка:

Использовать <br><br><br> для отступов между абзацами. Это ужасная практика! Для отступов есть CSS-свойство margin.

✅ Итоги урока:

  • <strong> — важность (жирный)
  • <em> — акцент (курсив)
  • <s> — зачёркнутый
  • <br> — перенос строки (одиночный)
  • <hr> — разделитель

🧠 Самостоятельная работа:

  1. Напиши отзыв на фильм, используя <strong> для оценок и <em> для названий.

  2. Создай стихотворение: <p> для строф, <br> для строк.

  3. Сделай объявление о скидках: <s> для старой цены, <strong> для новой.

🤖 Вопрос к размышлению:

Почему для перечёркивания лучше использовать <s>, а не CSS?

🎉 Бонус:

Твой текст теперь не просто «рыба», а живая, акцентированная речь! Ты закладываешь смысл в каждый элемент. 🎓
