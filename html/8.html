📝 Комментарии в коде — записки для себя и команды

🎯 Цель урока

Научиться писать комментарии в HTML для пояснения кода, невидимые для пользователя.

📚 Теория

Комментарий — текст для человека, который браузер полностью игнорирует. 

<!-- Это комментарий. Браузер меня не видит -->
<!-- ====== ШАПКА САЙТА ====== -->
<header>
    <!-- Основной логотип, ссылается на главную -->
    <a href="index.html">
        <img src="logo.png" alt="Логотип">
    </a>
    <!-- TODO: Доделать навигацию к пятнице -->
</header>

🔍 Разбор кода по косточкам:

  • <!-- ... --> — всё, что внутри, игнорируется браузером
  • Можно разбивать код на логические блоки
  • Можно оставлять TODO-заметки
  • Можно временно «выключать» код, не удаляя его

💡 Полезный совет:

Используй комментарии, чтобы временно скрыть блок кода. Оберни в <!-- ... --> — он исчезнет со страницы, но останется в коде.

⚠️ Типичная ошибка:

Писать очевидные комментарии. Плохо: <!-- Это картинка -->. Хорошо: <!-- Фото для карточки товара, загружается из админки -->. И не забывай закрывать комментарий!

✅ Итоги урока:

  • Синтаксис: <!-- текст -->
  • Не видны пользователю
  • Для пояснений, TODO, временного скрытия кода

🧠 Самостоятельная работа:

  1. Добавь комментарии-«шапки» к каждому разделу своей страницы.

  2. Напиши TODO-комментарий для себя.

  3. Закомментируй параграф, обнови браузер (исчез), потом верни обратно.

🤖 Вопрос к размышлению:

Почему грамотный комментарий важен для тебя самого через полгода?

🎉 Бонус:

Ты начал писать код не только для машин, но и для людей! Код становится чище и понятнее. 📈
