🧱 Сила объединения: div и span

🎯 Цель урока

Понять разницу между блочным элементом <div> и строчным <span>.

📚 Теория

  1. <div> — Блочный контейнер (Division)
    Как большая коробка. Занимает всю ширину, следующий элемент — с новой строки. 
    <div>
    <h2>Заголовок карточки</h2>
    <p>Описание внутри карточки.</p>
    <a href="#">Подробнее</a>
</div>
  2. <span> — Строчный контейнер
    Маленький пакетик внутри строки. Не начинает новую строку. 
    <p>Я люблю <span>зелёный</span> чай.</p>

🔍 Разбор кода по косточкам:

  • <div> = блочный, с новой строки, для группировки крупных блоков
  • <span> = строчный, внутри строки, для выделения слов
  • Сами по себе не несут смысла, но дают «крючки» для CSS и JS

💡 Полезный совет:

<div> — для блоков, <span> — для строки. Это фундамент всей вёрстки!

⚠️ Типичная ошибка:

«Div-ад» — использовать <div> везде, даже где можно семантические теги. И вкладывать блочный элемент в строчный — тоже ошибка.

✅ Итоги урока:

  • <div> — блочный несемантический контейнер
  • <span> — строчный несемантический контейнер
  • Дают «крючки» для CSS и JavaScript

🧠 Самостоятельная работа:

  1. Создай три «карточки» (заголовок + параграф), каждую оберни в <div>.

  2. Внутри параграфа оберни два слова в <span>.

  3. Опиши структуру страницы (шапка, меню, контент, подвал) с помощью <div> и комментариев.

🤖 Вопрос к размышлению:

Почему для стилизации используют <div>/<span>, а не вешают стили прямо на смысловые теги?
