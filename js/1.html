⚡ Что такое JavaScript и первая программа

🎯 Цель урока

Понять, что такое JavaScript, зачем он нужен, и написать свою первую программу с выводом в консоль и на экран.

📚 Теория

JavaScript — это язык программирования, который делает веб-страницы ИНТЕРАКТИВНЫМИ. Если HTML — скелет, CSS — кожа и одежда, то JavaScript — это МОЗГ и МЫШЦЫ! 🧠💪

Как подключить JavaScript к HTML:

1. Внутренний скрипт — тег <script> в HTML:\n

<body>
    <h1>Привет!</h1>
    <script>
        alert('Привет, мир!');
    </script>
</body>
2. Внешний скрипт (ЛУЧШИЙ способ!):
<script src="script.js"></script>
Подключать лучше в конце <body>, чтобы HTML загрузился первым.

Первые команды:
// Вывод в консоль браузера (F12 → Console)
console.log('Привет, консоль!');

// Всплывающее окно
alert('Привет, пользователь!');

// Вывод на страницу (заменит всё содержимое!)
document.write('Прямо на странице');

🔍 Разбор кода:

• <script> — тег для JavaScript-кода
• console.log() — вывод в консоль (главный инструмент разработчика)
• alert() — всплывающее окно с сообщением
• // — однострочный комментарий (браузер игнорирует)
• /* ... */ — многострочный комментарий
• Точка с запятой ; — конец инструкции (желательно, но не всегда обязательно)

💡 Полезный совет:

Всегда открывай Консоль (F12 → Console) при работе с JavaScript. Там видны все ошибки и результаты console.log(). Это твой лучший друг!

⚠️ Типичная ошибка:

Подключать скрипт в <head> без атрибутов defer или async. Скрипт начнёт выполняться до загрузки HTML, и элементы на странице будут недоступны. Подключай скрипт в конце <body>!

🧠 Самостоятельная работа:

📝 Задание 1: Создай HTML-страницу, подключи внешний JS-файл и выведи в консоль фразу «Я изучаю JavaScript!».

📝 Задание 2: Добавь alert() с любым сообщением. Проверь, что окно появляется при загрузке страницы.

📝 Задание 3: Намеренно допусти ошибку в коде (например, пропусти скобку) и посмотри, что покажет консоль.

🤖 Вопрос к размышлению:

Почему console.log() — главный инструмент разработчика, а не alert()?
