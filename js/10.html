🧱 Объекты: свойства, методы, this, перебор for...in

🎯 Цель урока

Научиться создавать объекты, работать со свойствами и методами, понимать ключевое слово this.

📚 Теория

Объект — это коллекция данных по принципу «ключ: значение». Как карточка товара или профиль пользователя.

Создание объекта:

const user = {
    name: 'Анна',
    age: 25,
    city: 'Москва',
    isAdmin: false,
    // Метод — функция внутри объекта
    greet() {
        console.log(`Привет, я ${this.name}!`);
    }
};


Доступ к свойствам:
// Точечная нотация
console.log(user.name);  // 'Анна'

// Скобочная нотация (ключ — строка или переменная)
console.log(user['age']);  // 25
let key = 'city';
console.log(user[key]);  // 'Москва'

// Добавление
user.email = 'anna@mail.com';

// Удаление
delete user.isAdmin;

// Проверка наличия
console.log('age' in user);  // true


Ключевое слово this:
const person = {
    name: 'Петя',
    sayName() {
        console.log(this.name);  // this = текущий объект
    }
};
person.sayName();  // 'Петя'


Перебор объекта:
for (let key in user) {
    console.log(`${key}: ${user[key]}`);
}

🔍 Разбор:

• { ключ: значение } — синтаксис объекта
• объект.свойство — точечный доступ
• объект['свойство'] — скобочный доступ (для переменных)
• this — ссылка на текущий объект внутри метода
• delete объект.свойство — удаление
• 'ключ' in объект — проверка наличия
• for...in — перебор ключей

💡 Полезный совет:

Используй точечную нотацию (user.name) когда знаешь точное имя свойства. Скобочную (user[key]) — когда имя свойства в переменной или вычисляется динамически.

⚠️ Типичная ошибка:

Путать . и []. user.key ищет свойство с именем «key». user[key] ищет свойство с именем, которое ЛЕЖИТ в переменной key.
