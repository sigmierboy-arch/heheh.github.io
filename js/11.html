🌳 DOM: что это и как с ним работать

🎯 Цель урока

Понять, что такое DOM-дерево, и научиться находить элементы на странице с помощью JavaScript.

📚 Теория

DOM (Document Object Model) — это представление HTML-страницы в виде дерева объектов, с которыми JavaScript может взаимодействовать.

Главный объект — document:

// Выведет весь HTML страницы
console.log(document);


Поиск элементов:
// По id (ОДИН элемент)
const header = document.getElementById('header');

// По классу (КОЛЛЕКЦИЯ, похожа на массив)
const cards = document.getElementsByClassName('card');

// По тегу (КОЛЛЕКЦИЯ)
const paragraphs = document.getElementsByTagName('p');

// УНИВЕРСАЛЬНЫЙ querySelector (ПЕРВЫЙ подходящий) 🔥
const firstCard = document.querySelector('.card');

// querySelectorAll (ВСЕ подходящие) 🔥
const allCards = document.querySelectorAll('.card');


Изменение содержимого:
const title = document.querySelector('h1');

title.textContent = 'Новый заголовок';  // только текст (безопасно)
title.innerHTML = 'Новый <span>заголовок</span>';  // HTML (осторожно!)


Изменение стилей:
const box = document.querySelector('.box');
box.style.backgroundColor = 'red';
box.style.fontSize = '20px';

🔍 Разбор:

• document — корневой объект всей страницы
• getElementById('id') — один элемент (быстрый)
• querySelector('селектор') — ПЕРВЫЙ по CSS-селектору
• querySelectorAll('селектор') — ВСЕ по CSS-селектору
• .textContent — ТОЛЬКО текст (безопасно от XSS)
• .innerHTML — HTML-код (опасно с пользовательским вводом!)
• .style.свойство — инлайн-стили

💡 Полезный совет:

Запомни: querySelector — универсальный (один элемент), querySelectorAll — универсальный (коллекция). Они понимают любой CSS-селектор: '.class', '#id', 'div > p'.

⚠️ Типичная ошибка:

Пытаться использовать методы DOM до загрузки страницы. Скрипт в <head> не видит <body>! Решение: размещать <script> в конце body или использовать DOMContentLoaded.
