🖱️ События: click, input, submit, клавиатура, мышь

🎯 Цель урока

Научиться обрабатывать события: клики, ввод текста, отправку форм, нажатия клавиш.

📚 Теория

Событие — это сигнал от браузера о том, что что-то произошло (клик, ввод, загрузка).\n\nСпособ 1: addEventListener (ЛУЧШИЙ! 🔥):\n

const button = document.querySelector('button');\n\nbutton.addEventListener('click', function() {\n    alert('Кнопка нажата!');\n});\n\n// Со стрелочной функцией:\nbutton.addEventListener('click', () => {\n    console.log('Клик!');\n});
\n\nСпособ 2: onclick (устаревший, только ОДИН обработчик):\n
button.onclick = function() {\n    alert('Клик!');\n};
\n\nПопулярные события:\n
// Мышь\nelement.addEventListener('click', handler);      // клик\nelement.addEventListener('dblclick', handler);   // двойной клик\nelement.addEventListener('mouseover', handler);  // наведение\nelement.addEventListener('mouseout', handler);   // уход курсора\n\n// Клавиатура\ndocument.addEventListener('keydown', handler);  // нажатие клавиши\ndocument.addEventListener('keyup', handler);    // отпускание\n\n// Формы\ninput.addEventListener('input', handler);   // ввод текста\ninput.addEventListener('change', handler);  // изменение + уход фокуса\nform.addEventListener('submit', handler);  // отправка формы\n\n// Загрузка\ndocument.addEventListener('DOMContentLoaded', handler); // DOM готов
\n\nОбъект события (event):\n
button.addEventListener('click', function(event) {\n    console.log(event.target);  // элемент, на котором сработало\n    console.log(event.type);    // 'click'\n    event.preventDefault();     // отменить действие по умолчанию\n});

🔍 Разбор:

• .addEventListener('событие', функция) — подписка\n• 'click' — клик мыши\n• 'input' — каждое изменение в поле ввода\n• 'submit' — отправка формы\n• 'keydown' — нажатие клавиши\n• event.target — кто вызвал событие\n• event.preventDefault() — отмена стандартного поведения

💡 Полезный совет:

Используй addEventListener вместо onclick. Он позволяет повесить НЕСКОЛЬКО обработчиков на одно событие и легко их удалять.

⚠️ Типичная ошибка:

Забыть про event.preventDefault() при отправке формы. Страница перезагрузится, и весь JavaScript-код потеряет состояние!
