🎨 Манипуляции с DOM: создание, добавление, удаление элементов

🎯 Цель урока

Научиться динамически создавать, добавлять, удалять и клонировать HTML-элементы с помощью JavaScript.

📚 Теория

JavaScript может не только читать, но и МЕНЯТЬ структуру страницы.

Создание элемента:

// Создать (пока не на странице)
const newDiv = document.createElement('div');

// Добавить класс
newDiv.classList.add('card');

// Добавить текст
newDiv.textContent = 'Я новый элемент!';

// Задать атрибут
newDiv.setAttribute('data-id', '123');


Добавление на страницу:
const parent = document.querySelector('.container');

// В конец родителя
parent.append(newDiv);

// В начало родителя
parent.prepend(newDiv);

// Перед элементом
target.before(newDiv);

// После элемента
target.after(newDiv);

// Старый способ (ещё работает)
parent.appendChild(newDiv);


Удаление:
element.remove();  // удалить элемент

// Старый способ
parent.removeChild(element);


Клонирование:
const clone = element.cloneNode(true);  // true = с содержимым


Работа с классами:
element.classList.add('active');     // добавить
classList.remove('hidden');   // удалить
classList.toggle('dark');     // переключить
classList.contains('active'); // проверить

🔍 Разбор:

• document.createElement('тег') — создать элемент
• .append() — добавить в конец (современный)
• .prepend() — добавить в начало
• .before() / .after() — рядом с элементом
• .remove() — удалить
• .cloneNode(true) — клонировать
• .classList — удобная работа с классами

💡 Полезный совет:

Создавай элемент, настраивай его (классы, текст, атрибуты), а потом ОДИН раз добавляй на страницу. Множество вставок по одной — медленно. Для массового добавления используй insertAdjacentHTML или DocumentFragment.

⚠️ Типичная ошибка:

Пытаться использовать append со строкой. parent.append('текст') — текст добавится как текстовый узел. Для HTML-строки используй insertAdjacentHTML('beforeend', '<div>HTML</div>').
