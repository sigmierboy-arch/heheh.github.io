📝 Работа с формами: получение значений, валидация

🎯 Цель урока

Научиться работать с HTML-формами: получать значения полей, проверять (валидировать) их и обрабатывать отправку.

📚 Теория

Получение значений из формы:

const form = document.querySelector('form');
const nameInput = document.querySelector('#name');
const emailInput = document.querySelector('#email');

form.addEventListener('submit', (event) => {
    event.preventDefault();  // отменяем перезагрузку!
    
    const name = nameInput.value;
    const email = emailInput.value;
    
    console.log({ name, email });
});


Типы полей и их значения:
// Текст, пароль, email
input.value

// Чекбокс (галочка)
checkbox.checked  // true/false

// Радио-кнопки
const selected = document.querySelector('input[name="gender"]:checked');
selected.value

// Select
select.value

// Textarea
textarea.value


Простая валидация:
form.addEventListener('submit', (event) => {
    const email = emailInput.value;
    
    if (!email.includes('@')) {
        alert('Введите корректный email!');
        event.preventDefault();  // не отправлять!
        return;
    }
    
    if (nameInput.value.trim() === '') {
        alert('Имя не может быть пустым!');
        event.preventDefault();
        return;
    }
});


Событие input (реакция на лету):
nameInput.addEventListener('input', () => {
    const value = nameInput.value;
    const errorSpan = document.querySelector('.error');
    
    if (value.length < 3) {
        errorSpan.textContent = 'Минимум 3 символа';
    } else {
        errorSpan.textContent = '';
    }
});

🔍 Разбор:

• event.preventDefault() — ОБЯЗАТЕЛЬНО при submit!
• input.value — текст из поля
• checkbox.checked — true/false
• input.value.trim() — удалить пробелы по краям
• Валидация — проверка ДО отправки
• 'input' — событие при КАЖДОМ изменении

💡 Полезный совет:

Валидируй на клиенте (в браузере) ДЛЯ УДОБСТВА пользователя (быстрые подсказки). Но ВСЕГДА проверяй данные и на сервере! Клиентскую валидацию легко обойти.

⚠️ Типичная ошибка:

Забыть event.preventDefault() при отправке формы. Страница перезагрузится, все данные потеряются, а консоль очистится. Это САМАЯ частая ошибка новичков!

✅ Итоги урока:

✅ event.preventDefault() — отмена отправки
✅ input.value — значение поля
✅ checkbox.checked — состояние чекбокса
✅ Валидация = проверка + сообщение об ошибке
✅ Проверяй на клиенте И на сервере

🧠 Самостоятельная работа:

📝 Задание 1: Создай форму входа (email + пароль). При отправке выводи значения в консоль.

📝 Задание 2: Добавь валидацию: email должен содержать '@', пароль — минимум 6 символов.

📝 Задание 3: Реализуй live-валидацию: при вводе сразу показывай, корректен ли email.
