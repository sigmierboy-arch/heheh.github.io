⏰ Таймеры: setTimeout, setInterval

🎯 Цель урока

Научиться откладывать выполнение кода (setTimeout) и выполнять его периодически (setInterval).

📚 Теория

1. setTimeout — выполнить ОДИН раз через задержку:\n

// Через 3 секунды покажет сообщение\nsetTimeout(() => {\n    console.log('Прошло 3 секунды!');\n}, 3000);  // время в миллисекундах\n\n// С отменой\nconst timerId = setTimeout(() => {\n    console.log('Не увидишь это');\n}, 5000);\nclearTimeout(timerId);  // отменили!
\n\n2. setInterval — повторять КАЖДЫЕ N миллисекунд:\n
// Каждую секунду выводить в консоль\nconst intervalId = setInterval(() => {\n    console.log('Тик!');\n}, 1000);\n\n// Остановить через 5 секунд\nsetTimeout(() => {\n    clearInterval(intervalId);\n    console.log('Остановлено!');\n}, 5000);
\n\nПрактический пример — таймер обратного отсчёта:\n
let seconds = 10;\nconst timerElement = document.querySelector('#timer');\n\nconst countdown = setInterval(() => {\n    seconds--;\n    timerElement.textContent = seconds;\n    \n    if (seconds <= 0) {\n        clearInterval(countdown);\n        timerElement.textContent = 'Время вышло!';\n    }\n}, 1000);

🔍 Разбор:

• setTimeout(функция, задержка_в_мс) — один раз\n• setInterval(функция, интервал_в_мс) — повторять\n• 1000 мс = 1 секунда\n• clearTimeout(id) / clearInterval(id) — отмена\n• Сохраняй ID таймера для возможности отмены\n• Важно: таймеры продолжают работать, даже если пользователь ушёл со вкладки (но с пониженной частотой)

💡 Полезный совет:

Для анимаций лучше использовать requestAnimationFrame, а не setInterval. Для периодических задач (например, автосохранение) — setInterval. Для задержек — setTimeout.

⚠️ Типичная ошибка:

Забыть очистить интервал при уходе со страницы. Интервал продолжит работать, нагружая браузер, и может вызвать ошибки при попытке обновить уже несуществующие элементы.

✅ Итоги урока:

✅ setTimeout(fn, ms) — задержка, один раз\n✅ setInterval(fn, ms) — повторение\n✅ clearTimeout(id) / clearInterval(id) — отмена\n✅ Всегда сохраняй ID и очищай при необходимости

🧠 Самостоятельная работа:

📝 Задание 1: Выведи сообщение «Привет!» с задержкой в 2 секунды после загрузки страницы.\n\n📝 Задание 2: Создай таймер обратного отсчёта от 10 до 0. Когда 0 — выведи «Финиш!».\n\n📝 Задание 3: Создай кнопку «Старт» (запускает интервал, который выводит время) и «Стоп» (останавливает).
