⏰ Таймеры: setTimeout, setInterval

🎯 Цель урока

Научиться откладывать выполнение кода (setTimeout) и выполнять его периодически (setInterval).

📚 Теория

1. setTimeout — выполнить ОДИН раз через задержку:

// Через 3 секунды покажет сообщение
setTimeout(() => {
    console.log('Прошло 3 секунды!');
}, 3000);  // время в миллисекундах

// С отменой
const timerId = setTimeout(() => {
    console.log('Не увидишь это');
}, 5000);
clearTimeout(timerId);  // отменили!


2. setInterval — повторять КАЖДЫЕ N миллисекунд:
// Каждую секунду выводить в консоль
const intervalId = setInterval(() => {
    console.log('Тик!');
}, 1000);

// Остановить через 5 секунд
setTimeout(() => {
    clearInterval(intervalId);
    console.log('Остановлено!');
}, 5000);


Практический пример — таймер обратного отсчёта:
let seconds = 10;
const timerElement = document.querySelector('#timer');

const countdown = setInterval(() => {
    seconds--;
    timerElement.textContent = seconds;
    
    if (seconds <= 0) {
        clearInterval(countdown);
        timerElement.textContent = 'Время вышло!';
    }
}, 1000);

🔍 Разбор:

• setTimeout(функция, задержка_в_мс) — один раз
• setInterval(функция, интервал_в_мс) — повторять
• 1000 мс = 1 секунда
• clearTimeout(id) / clearInterval(id) — отмена
• Сохраняй ID таймера для возможности отмены
• Важно: таймеры продолжают работать, даже если пользователь ушёл со вкладки (но с пониженной частотой)

💡 Полезный совет:

Для анимаций лучше использовать requestAnimationFrame, а не setInterval. Для периодических задач (например, автосохранение) — setInterval. Для задержек — setTimeout.

⚠️ Типичная ошибка:

Забыть очистить интервал при уходе со страницы. Интервал продолжит работать, нагружая браузер, и может вызвать ошибки при попытке обновить уже несуществующие элементы.

✅ Итоги урока:

✅ setTimeout(fn, ms) — задержка, один раз
✅ setInterval(fn, ms) — повторение
✅ clearTimeout(id) / clearInterval(id) — отмена
✅ Всегда сохраняй ID и очищай при необходимости
