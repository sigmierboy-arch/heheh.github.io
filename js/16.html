🌐 Асинхронность: Promise, .then(), .catch()

🎯 Цель урока

Понять, что такое асинхронность, и научиться работать с Promise: создавать, обрабатывать результат и ошибки.

📚 Теория

Асинхронность — это способность выполнять код, не блокируя основной поток. Как заказ пиццы: ты сделал заказ и можешь заниматься делами, пока её готовят.

Promise (Обещание) — объект, который представляет результат асинхронной операции.

Состояния Promise:
• pending — ожидание (пицца готовится)
• fulfilled — выполнено успешно (пицца приехала!)
• rejected — ошибка (пиццу не довезли)

Создание Promise:

const myPromise = new Promise((resolve, reject) => {
    // асинхронная операция
    setTimeout(() => {
        const success = true;
        if (success) {
            resolve('Успех! 🎉');
        } else {
            reject('Ошибка! 💥');
        }
    }, 2000);
});


Обработка Promise:
myPromise
    .then(result => {
        console.log('Результат:', result);  // 'Успех! 🎉'
    })
    .catch(error => {
        console.error('Ошибка:', error);
    })
    .finally(() => {
        console.log('Операция завершена (в любом случае)');
    });


Цепочки Promise:
fetchUser(1)
    .then(user => fetchPosts(user.id))
    .then(posts => console.log(posts))
    .catch(error => console.error('Где-то ошибка:', error));

🔍 Разбор:

• new Promise((resolve, reject) => {...}) — создание
• resolve(данные) — успех, переходит в .then()
• reject(ошибка) — ошибка, переходит в .catch()
• .then() — обработка успеха
• .catch() — обработка ошибки
• .finally() — выполнится всегда
• Цепочка: .then().then().catch()

💡 Полезный совет:

Всегда добавляй .catch() в конце цепочки! Необработанные ошибки в Promise могут «упасть» молча, и ты не узнаешь, что что-то сломалось.

⚠️ Типичная ошибка:

Забыть вернуть (return) Promise в цепочке .then().

fetchUser(1)
    .then(user => {
        fetchPosts(user.id);  // ЗАБЫЛИ return!
    })
    .then(posts => console.log(posts));  // undefined!

✅ Итоги урока:

✅ Promise — объект для асинхронных операций
✅ resolve() → .then()
✅ reject() → .catch()
✅ .finally() — в любом случае
✅ Цепочки: .then().then().catch()
✅ Всегда возвращай Promise в .then()
