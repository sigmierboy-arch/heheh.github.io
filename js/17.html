🚀 Async/Await — асинхронность без боли

🎯 Цель урока

Освоить async/await — современный и элегантный способ работы с асинхронным кодом.

📚 Теория

async/await — это «сахар» над Promise, который позволяет писать асинхронный код так, как будто он синхронный.

async-функция:

// async всегда возвращает Promise
async function fetchData() {
    return 'Данные';
}
// Эквивалентно:
function fetchData() {
    return Promise.resolve('Данные');
}


await — ждём результат:
async function getUser() {
    // await можно использовать ТОЛЬКО внутри async-функции
    const response = await fetch('https://api.example.com/user');
    const user = await response.json();
    return user;
}


Обработка ошибок с try/catch:
async function loadData() {
    try {
        const user = await fetchUser();
        const posts = await fetchPosts(user.id);
        console.log(posts);
    } catch (error) {
        console.error('Что-то пошло не так:', error);
    } finally {
        console.log('Загрузка завершена');
    }
}


Сравнение Promise и async/await:
// Promise
fetchUser()
    .then(user => fetchPosts(user.id))
    .then(posts => console.log(posts))
    .catch(error => console.error(error));

// async/await (читается как обычный код!)
async function load() {
    try {
        const user = await fetchUser();
        const posts = await fetchPosts(user.id);
        console.log(posts);
    } catch (error) {
        console.error(error);
    }
}

🔍 Разбор:

• async перед функцией — она вернёт Promise
• await — ждёт выполнения Promise (только внутри async)
• try { ... } catch(error) { ... } — обработка ошибок
• Код после await выполнится, когда Promise разрешится
• Выглядит как синхронный код, но не блокирует поток!

💡 Полезный совет:

Всегда оборачивай await в try/catch. Если Promise отклонится, ошибка будет поймана, и приложение не упадёт. Забыл catch — получил необработанную ошибку!

⚠️ Типичная ошибка:

Использовать await вне async-функции. На верхнем уровне (в глобальной области) await можно использовать только в ES модулях. В обычном скрипте — только внутри async function.
