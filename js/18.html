🌍 Fetch API: общение с сервером (GET, POST, JSON)

🎯 Цель урока

Научиться получать данные с сервера и отправлять их с помощью Fetch API.

📚 Теория

Fetch API — это современный способ отправлять HTTP-запросы из браузера.

GET-запрос (получить данные):

async function getUsers() {
    const response = await fetch('https://jsonplaceholder.typicode.com/users');
    
    if (!response.ok) {
        throw new Error(`Ошибка HTTP: ${response.status}`);
    }
    
    const users = await response.json();  // парсим JSON
    console.log(users);
    return users;
}


POST-запрос (отправить данные):
async function createUser(userData) {
    const response = await fetch('https://api.example.com/users', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
        },
        body: JSON.stringify(userData),  // объект → JSON-строка
    });
    
    const result = await response.json();
    console.log('Создано:', result);
    return result;
}

// Использование:
createUser({ name: 'Иван', email: 'ivan@mail.com' });


Другие методы:
// PUT — полностью обновить
fetch(url, { method: 'PUT', body: JSON.stringify(data) });

// PATCH — частично обновить
fetch(url, { method: 'PATCH', body: JSON.stringify(data) });

// DELETE — удалить
fetch(url, { method: 'DELETE' });


Обработка ошибок:
async function fetchWithError(url) {
    try {
        const response = await fetch(url);
        
        if (!response.ok) {
            throw new Error(`Сервер ответил: ${response.status}`);
        }
        
        return await response.json();
    } catch (error) {
        console.error('Ошибка сети или сервера:', error);
        throw error;  // пробрасываем дальше
    }
}

🔍 Разбор:

• fetch(url, options) — возвращает Promise
• response.ok — true если статус 200-299
• response.json() — парсинг JSON-ответа
• JSON.stringify(obj) — объект в JSON-строку
• headers — заголовки запроса
• method — HTTP-метод (GET, POST, PUT, DELETE)
• body — тело запроса (для POST/PUT/PATCH)

💡 Полезный совет:

Всегда проверяй response.ok! fetch отклоняет Promise ТОЛЬКО при ошибке сети. Ответ 404 или 500 — это УСПЕШНЫЙ fetch (с точки зрения сети), но ok: false.

⚠️ Типичная ошибка:

Забыть await response.json() и пытаться использовать response как данные. response — это объект ответа, а не сами данные. Данные получаем через .json().
