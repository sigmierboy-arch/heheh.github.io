🌍 Fetch API: общение с сервером (GET, POST, JSON)

🎯 Цель урока

Научиться получать данные с сервера и отправлять их с помощью Fetch API.

📚 Теория

Fetch API — это современный способ отправлять HTTP-запросы из браузера.\n\nGET-запрос (получить данные):\n

async function getUsers() {\n    const response = await fetch('https://jsonplaceholder.typicode.com/users');\n    \n    if (!response.ok) {\n        throw new Error(`Ошибка HTTP: ${response.status}`);\n    }\n    \n    const users = await response.json();  // парсим JSON\n    console.log(users);\n    return users;\n}
\n\nPOST-запрос (отправить данные):\n
async function createUser(userData) {\n    const response = await fetch('https://api.example.com/users', {\n        method: 'POST',\n        headers: {\n            'Content-Type': 'application/json',\n        },\n        body: JSON.stringify(userData),  // объект → JSON-строка\n    });\n    \n    const result = await response.json();\n    console.log('Создано:', result);\n    return result;\n}\n\n// Использование:\ncreateUser({ name: 'Иван', email: 'ivan@mail.com' });
\n\nДругие методы:\n
// PUT — полностью обновить\nfetch(url, { method: 'PUT', body: JSON.stringify(data) });\n\n// PATCH — частично обновить\nfetch(url, { method: 'PATCH', body: JSON.stringify(data) });\n\n// DELETE — удалить\nfetch(url, { method: 'DELETE' });
\n\nОбработка ошибок:\n
async function fetchWithError(url) {\n    try {\n        const response = await fetch(url);\n        \n        if (!response.ok) {\n            throw new Error(`Сервер ответил: ${response.status}`);\n        }\n        \n        return await response.json();\n    } catch (error) {\n        console.error('Ошибка сети или сервера:', error);\n        throw error;  // пробрасываем дальше\n    }\n}

🔍 Разбор:

• fetch(url, options) — возвращает Promise\n• response.ok — true если статус 200-299\n• response.json() — парсинг JSON-ответа\n• JSON.stringify(obj) — объект в JSON-строку\n• headers — заголовки запроса\n• method — HTTP-метод (GET, POST, PUT, DELETE)\n• body — тело запроса (для POST/PUT/PATCH)

💡 Полезный совет:

Всегда проверяй response.ok! fetch отклоняет Promise ТОЛЬКО при ошибке сети. Ответ 404 или 500 — это УСПЕШНЫЙ fetch (с точки зрения сети), но ok: false.

⚠️ Типичная ошибка:

Забыть await response.json() и пытаться использовать response как данные. response — это объект ответа, а не сами данные. Данные получаем через .json().

🧠 Самостоятельная работа:
