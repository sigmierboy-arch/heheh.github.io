💾 LocalStorage: сохраняем данные в браузере

🎯 Цель урока

Научиться сохранять данные в браузере пользователя с помощью LocalStorage и SessionStorage.

📚 Теория

LocalStorage — это хранилище «ключ-значение» в браузере. Данные сохраняются даже после закрытия браузера!

Основные операции:

// Сохранить (только строки!)
localStorage.setItem('username', 'Анна');

// Получить
const name = localStorage.getItem('username');
console.log(name);  // 'Анна'

// Удалить конкретный ключ
localStorage.removeItem('username');

// Очистить ВСЁ хранилище
localStorage.clear();

// Количество записей
console.log(localStorage.length);


Хранение объектов (сериализация):
const user = {
    name: 'Петя',
    age: 30,
    settings: { theme: 'dark' }
};

// Сохраняем объект → JSON-строка
localStorage.setItem('user', JSON.stringify(user));

// Получаем JSON-строку → объект
const savedUser = JSON.parse(localStorage.getItem('user'));
console.log(savedUser.name);  // 'Петя'


Практический пример — тёмная тема:
// При загрузке страницы
const savedTheme = localStorage.getItem('theme');
if (savedTheme === 'dark') {
    document.body.classList.add('dark-mode');
}

// При переключении
button.addEventListener('click', () => {
    document.body.classList.toggle('dark-mode');
    const currentTheme = document.body.classList.contains('dark-mode') 
        ? 'dark' 
        : 'light';
    localStorage.setItem('theme', currentTheme);
});


SessionStorage — то же самое, но данные живут только до закрытия вкладки:
sessionStorage.setItem('temp', 'временные данные');

🔍 Разбор:

• localStorage.setItem('ключ', 'значение') — сохранить
• localStorage.getItem('ключ') — получить
• localStorage.removeItem('ключ') — удалить один
• localStorage.clear() — удалить всё
• JSON.stringify(obj) — объект → строка
• JSON.parse(str) — строка → объект
• LocalStorage живёт вечно (пока не удалят), SessionStorage — до закрытия вкладки

💡 Полезный совет:

LocalStorage отлично подходит для: темы оформления, настроек пользователя, черновиков форм, токенов авторизации (НЕ паролей!). Максимальный размер — около 5-10 МБ.

⚠️ Типичная ошибка:

Пытаться сохранить объект напрямую: localStorage.setItem('user', user). Сохранится строка [object Object]! Всегда используй JSON.stringify()
