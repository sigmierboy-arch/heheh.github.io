📦 Переменные: let, const и var

🎯 Цель урока

Научиться создавать переменные с помощью let и const, понять основные типы данных и разницу между ними.

📚 Теория

Переменная — это как коробка с этикеткой, в которой мы храним данные.

Три способа объявить переменную:

// СОВРЕМЕННЫЙ способ (меняется)
let name = 'Анна';
let age = 25;

// КОНСТАНТА (не меняется)
const PI = 3.14159;
const BIRTH_YEAR = 1999;

// УСТАРЕВШИЙ (не используй!)
var oldWay = 'не надо так';


Основные типы данных:
// Число (Number)
let count = 42;
let price = 19.99;

// Строка (String)
let message = 'Привет!';
let name = "Иван";
let template = `Привет, ${name}!`; // шаблонная строка

// Булево (Boolean)
let isLoggedIn = true;
let isAdmin = false;

// null — «ничего», пусто
let empty = null;

// undefined — значение не присвоено
let notDefined;
console.log(notDefined); // undefined

🔍 Разбор:

• let — переменная, можно перезаписывать
• const — константа, НЕЛЬЗЯ перезаписывать (но объекты/массивы внутри менять можно)
• var — НЕ ИСПОЛЬЗУЙ (устарел, странная область видимости)
• ${} — вставка переменной в шаблонную строку (обратные кавычки!)
• Типы: Number, String, Boolean, null, undefined

💡 Полезный совет:

По умолчанию используй const! Если знаешь, что значение будет меняться — только тогда let. Это делает код предсказуемее и защищает от случайных перезаписей.

⚠️ Типичная ошибка:

Пытаться перезаписать const. const x = 5; x = 10; — ОШИБКА! Консоль покажет TypeError: Assignment to constant variable.
