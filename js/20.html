🏆 Итоговый проект «ToDo-приложение с нуля»

🎯 Цель урока

Консолидировать все знания и создать завершённое веб-приложение «Список задач» с сохранением в LocalStorage.

📚 Техническое задание (ТЗ) на проект

Создай приложение для управления задачами. Файлы: index.html, style.css, app.js.

Функционал:

1. Добавление задачи:
• Поле ввода + кнопка «Добавить»
• При клике задача добавляется в список
• Пустые задачи не добавляются (валидация!)
• После добавления поле очищается

2. Отображение списка:
• Каждая задача — элемент списка
• Показывать: текст задачи, дату создания, статус

3. Управление задачами:
• Отметить как выполненную (зачёркивание текста)
• Удалить задачу (кнопка с крестиком)
• Редактировать задачу (двойной клик для редактирования)

4. Статистика:
• Счётчик: «Всего: X, Выполнено: Y»
• Прогресс-бар выполнения

5. Фильтрация:
• Кнопки: «Все», «Активные», «Выполненные»
• При клике показывать соответствующие задачи

6. Сохранение данных:
• Все задачи хранятся в LocalStorage
• При загрузке страницы восстанавливаются
• Автосохранение при любом изменении

7. Бонусные фичи:
• Анимация добавления/удаления
• Очистка всех выполненных задач
• Drag-and-drop для перестановки

8. Дизайн:
• Красивый современный интерфейс
• Адаптивность (мобильные + десктоп)
• Тёмная тема (сохраняется!)
