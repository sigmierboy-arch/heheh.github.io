🔢 Операторы: арифметика, сравнение, логика

🎯 Цель урока

Освоить основные операторы JavaScript: арифметические, присваивания, сравнения и логические.

📚 Теория

1. Арифметические операторы:

let x = 10;
let y = 3;

console.log(x + y);  // 13 (сложение)
console.log(x - y);  // 7  (вычитание)
console.log(x * y);  // 30 (умножение)
console.log(x / y);  // 3.333... (деление)
console.log(x % y);  // 1  (остаток от деления)
console.log(x ** y); // 1000 (возведение в степень)


Инкремент / Декремент:
let count = 0;
count++;  // увеличить на 1 (теперь 1)
count--;  // уменьшить на 1 (теперь 0)


2. Операторы сравнения (возвращают Boolean):
console.log(5 > 3);   // true
console.log(5 < 3);   // false
console.log(5 >= 5);  // true
console.log(5 === 5); // true (строгое равенство)
console.log(5 === '5'); // false (разные типы!)
console.log(5 == '5');  // true (нестрогое, с приведением типов)
console.log(5 !== 3); // true (строгое неравенство)


3. Логические операторы:
// И (оба условия true)
console.log(true && true);   // true
console.log(true && false);  // false

// ИЛИ (хотя бы одно true)
console.log(true || false);  // true
console.log(false || false); // false

// НЕ (отрицание)
console.log(!true);  // false
console.log(!false); // true

🔍 Разбор:

• ** — возведение в степень (ES6+)
• % — остаток от деления (проверка чётности: x % 2 === 0)
• === — СТРОГОЕ равенство (ВСЕГДА используй его!)
• == — НЕСТРОГОЕ равенство (избегай, приводит типы)
• && — логическое И
• || — логическое ИЛИ
• ! — логическое НЕ

💡 Полезный совет:

Всегда используй строгое равенство === и строгое неравенство !==. Нестрогие операторы == и != могут дать неожиданные результаты из-за приведения типов.

⚠️ Типичная ошибка:

Путать = (присваивание) и === (сравнение). if (x = 5) — всегда true, потому что это присваивание! Правильно: if (x === 5).

✅ Итоги урока:

✅ Арифметика: + - * / % **
✅ Сравнение: > < >= <= === !==
✅ Логика: && || !
✅ Всегда ===, никогда ==
