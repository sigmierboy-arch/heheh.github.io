🔀 Условные конструкции: if, else, else if, тернарный оператор, switch

🎯 Цель урока

Научиться управлять потоком выполнения программы с помощью условных конструкций.

📚 Теория

1. if / else if / else:

let hour = 14;

if (hour < 12) {
    console.log('Доброе утро!');
} else if (hour < 18) {
    console.log('Добрый день!');
} else {
    console.log('Добрый вечер!');
}


2. Тернарный оператор (короткий if-else):
let age = 20;
let status = age >= 18 ? 'Совершеннолетний' : 'Несовершеннолетний';
// условие ? если_да : если_нет


3. switch — для множества конкретных значений:
let day = 'вторник';

switch (day) {
    case 'понедельник':
        console.log('Начало недели 😩');
        break;
    case 'пятница':
        console.log('Ура! 🎉');
        break;
    case 'суббота':
    case 'воскресенье':
        console.log('Выходные! 😴');
        break;
    default:
        console.log('Обычный день');
}

🔍 Разбор:

• if (условие) { ... } — выполнится, если условие true
• else if — дополнительная проверка
• else — если ни одно условие не подошло
• условие ? да : нет — тернарный оператор (в одну строку!)
• switch — перебор вариантов, break обязателен!
• default — аналог else в switch

💡 Полезный совет:

Тернарный оператор — отличный способ присвоить значение по условию в одну строку. Но не вкладывай тернарные операторы друг в друга — код станет нечитаемым!

⚠️ Типичная ошибка:

Забыть break в switch. Без break выполнение «провалится» в следующий case! Иногда это нужно специально, но обычно — ошибка.

✅ Итоги урока:

✅ if / else if / else — условные ветвления
✅ Тернарный оператор: условие ? да : нет
✅ switch / case / break / default — для множества вариантов
✅ Фигурные скобки { } — тело условия
