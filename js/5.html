🔄 Циклы: for, while, do...while

🎯 Цель урока

Научиться выполнять повторяющиеся действия с помощью циклов и управлять ими с помощью break и continue.

📚 Теория

Циклы позволяют выполнять код много раз.

1. for — когда известно количество итераций:

for (let i = 0; i < 5; i++) {
    console.log(`Итерация №${i + 1}`);
}
// Выведет 5 раз: Итерация №1, №2, ...


Структура for:
for (начало; условие; шаг) {
    // тело цикла
}


2. while — пока условие true:
let count = 0;
while (count < 3) {
    console.log('Счёт: ' + count);
    count++;
}


3. do...while — сначала выполнит, потом проверит:
let x = 0;
do {
    console.log('Выполнится хотя бы раз');
    x++;
} while (x < 0); // условие false, но первый раз сработало!


Управление циклом:
// break — выйти из цикла
for (let i = 0; i < 10; i++) {
    if (i === 5) break;  // выйдем на 5
    console.log(i);
}

// continue — пропустить итерацию
for (let i = 0; i < 5; i++) {
    if (i === 2) continue;  // пропустим 2
    console.log(i);  // 0, 1, 3, 4
}

🔍 Разбор:

• for (let i = 0; i < 5; i++) — классический счётчик
• while (условие) — неизвестно сколько итераций
• do...while — гарантированно 1 раз
• break — экстренный выход
• continue — переход к следующей итерации
• Осторожно с бесконечными циклами!

💡 Полезный совет:

Используй for, когда знаешь количество итераций (массив, счётчик). Используй while, когда ждёшь условие (например, ответ от сервера).

⚠️ Типичная ошибка:

Бесконечный цикл! Если условие никогда не станет false — страница зависнет.

let i = 0;
while (i < 10) {
    console.log(i);
    // ЗАБЫЛИ i++ !!! Бесконечный цикл!
}

✅ Итоги урока:

✅ for — цикл со счётчиком
✅ while — цикл с условием
✅ do...while — минимум 1 итерация
✅ break — выход, continue — пропуск
✅ Всегда проверяй условие выхода!
