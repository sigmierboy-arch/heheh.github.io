📋 Массивы: создание, доступ, методы push, pop, shift, unshift, splice

🎯 Цель урока

Научиться создавать массивы, получать доступ к элементам по индексу и использовать основные методы для работы с массивами.

📚 Теория

Массив — это упорядоченная коллекция данных. Как список покупок или плейлист.

Создание и доступ:

// Создание
let fruits = ['яблоко', 'банан', 'апельсин'];
let numbers = [1, 2, 3, 4, 5];
let mixed = [42, 'привет', true, null];

// Доступ по индексу (начинается с 0!)
console.log(fruits[0]);  // 'яблоко'
console.log(fruits[1]);  // 'банан'
console.log(fruits[2]);  // 'апельсин'

// Длина массива
console.log(fruits.length);  // 3


Методы массивов:
let arr = [1, 2, 3];

// ДОБАВЛЕНИЕ
arr.push(4);        // в конец → [1,2,3,4]
arr.unshift(0);     // в начало → [0,1,2,3,4]

// УДАЛЕНИЕ
arr.pop();          // с конца (вернёт 4) → [0,1,2,3]
arr.shift();        // с начала (вернёт 0) → [1,2,3]

// УНИВЕРСАЛЬНЫЙ splice
arr.splice(1, 1, 'x', 'y');
// начиная с индекса 1, удалить 1 элемент, вставить 'x','y'
// Было [1,2,3] → Стало [1,'x','y',3]

🔍 Разбор:

• arr[0] — первый элемент (индексы с 0!)
• arr.length — длина массива
• .push(элемент) — добавить в КОНЕЦ (чаще всего!)
• .pop() — удалить с конца (вернёт удалённое)
• .unshift(элемент) — добавить в НАЧАЛО
• .shift() — удалить с начала
• .splice(начало, сколько_удалить, что_вставить) — швейцарский нож

💡 Полезный совет:

Запомни: push/pop — работа с КОНЦОМ (быстро). unshift/shift — работа с НАЧАЛОМ (медленнее, сдвигает все элементы). Для производительности лучше использовать push/pop.

⚠️ Типичная ошибка:

Забыть, что индексы начинаются с 0. arr[1] — это ВТОРОЙ элемент! И arr[arr.length] — не последний, а ЗА последним (undefined). Последний: arr[arr.length - 1].
