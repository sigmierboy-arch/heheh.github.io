🔁 Методы массивов: forEach, map, filter, find, reduce

🎯 Цель урока

Освоить функциональные методы массивов, которые заменяют циклы и делают код чище и выразительнее.

📚 Теория

Современный JavaScript предлагает крутые методы для работы с массивами. Они принимают колбэк-функцию.

1. forEach — просто перебрать (без возврата):

let fruits = ['яблоко', 'банан', 'киви'];
fruits.forEach(function(item, index) {
    console.log(`${index}: ${item}`);
});
// 0: яблоко, 1: банан, 2: киви


2. map — ТРАНСФОРМИРОВАТЬ каждый элемент (возвращает новый массив!):
let numbers = [1, 2, 3];
let doubled = numbers.map(n => n * 2);
console.log(doubled);  // [2, 4, 6]


3. filter — ОТФИЛЬТРОВАТЬ (вернуть только подходящие):
let ages = [12, 18, 25, 14, 30];
let adults = ages.filter(age => age >= 18);
console.log(adults);  // [18, 25, 30]


4. find — НАЙТИ первый подходящий:
let users = [
    {name: 'Аня', age: 25},
    {name: 'Ваня', age: 17},
    {name: 'Катя', age: 30}
];
let user = users.find(u => u.age > 18);
console.log(user);  // {name: 'Аня', age: 25}


5. reduce — СВЕРНУТЬ массив в одно значение:
let numbers = [1, 2, 3, 4, 5];
let sum = numbers.reduce((accumulator, current) => accumulator + current, 0);
console.log(sum);  // 15

🔍 Разбор:

• .forEach() — перебор, ничего не возвращает
• .map() — новый массив той же длины (трансформация)
• .filter() — новый массив с подходящими элементами
• .find() — первый подходящий элемент (или undefined)
• .reduce() — аккумуляция (сумма, объект, строка)
• Стрелочная функция: item => item * 2

💡 Полезный совет:

Выбирай правильный метод:
• Просто пройтись → forEach
• Изменить каждый → map
• Отобрать → filter
• Найти один → find
• Посчитать сумму/объединить → reduce

⚠️ Типичная ошибка:

Думать, что map меняет исходный массив. НЕТ! map возвращает НОВЫЙ массив. Исходный остаётся неизменным (иммутабельность!).
