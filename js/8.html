📝 Строки: методы, шаблонные строки, работа с текстом

🎯 Цель урока

Освоить основные методы для работы со строками в JavaScript: от изменения регистра до поиска и замены.

📚 Теория

Строки в JavaScript неизменяемы (immutable). Все методы возвращают НОВУЮ строку.

Основные методы строк:

let str = 'Привет, Мир!';

// Длина строки
console.log(str.length);  // 13

// Регистр
console.log(str.toUpperCase());  // 'ПРИВЕТ, МИР!'
console.log(str.toLowerCase());  // 'привет, мир!'

// Поиск подстроки
console.log(str.includes('Мир'));    // true
console.log(str.indexOf('Мир'));     // 8 (позиция)
console.log(str.startsWith('При'));  // true
console.log(str.endsWith('!'));      // true

// Извлечение
console.log(str.slice(0, 6));   // 'Привет'
console.log(str.slice(8));      // 'Мир!'
console.log(str.substring(0, 6)); // 'Привет'

// Замена
console.log(str.replace('Мир', 'JavaScript')); // 'Привет, JavaScript!'
console.log(str.replaceAll('и', 'ы')); // замена всех

// Разбиение в массив
console.log(str.split(', '));  // ['Привет', 'Мир!']

// Удаление пробелов
let raw = '   текст   ';
console.log(raw.trim());  // 'текст'

🔍 Разбор:

• .length — длина строки (свойство, не метод!)
• .toUpperCase() / .toLowerCase() — регистр
• .includes() — есть ли подстрока (true/false)
• .indexOf() — позиция подстроки (-1 если нет)
• .slice(начало, конец) — извлечь часть
• .replace() — заменить ПЕРВОЕ вхождение
• .replaceAll() — заменить ВСЕ вхождения
• .split() — разбить в массив
• .trim() — убрать пробелы по краям

💡 Полезный совет:

Для поиска используй .includes() (просто есть/нет). Для получения позиции — .indexOf(). .slice() работает с отрицательными индексами (с конца): str.slice(-3) — последние 3 символа.

⚠️ Типичная ошибка:

Забыть, что строки неизменяемы. str.toUpperCase() не меняет str! Надо: str = str.toUpperCase();
