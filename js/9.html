🔧 Функции: объявление, параметры, return, стрелочные функции

🎯 Цель урока

Научиться создавать функции — переиспользуемые блоки кода, принимать параметры и возвращать результат.

📚 Теория

Функция — это блок кода, который можно вызвать много раз. Как рецепт: один раз записал — используешь когда угодно.

1. Function Declaration (классическая):

function greet(name) {
    return `Привет, ${name}!`;
}
console.log(greet('Анна')); // 'Привет, Анна!'


2. Function Expression (функция в переменной):
const greet = function(name) {
    return `Привет, ${name}!`;
};


3. Стрелочная функция (современно! 🔥):
const greet = (name) => {
    return `Привет, ${name}!`;
};
// Короткая форма (если одна операция):
const greet = name => `Привет, ${name}!`;


Параметры и return:
function sum(a, b) {
    return a + b;
}
let result = sum(5, 3);  // 8

// Параметры по умолчанию
function greet(name = 'Гость') {
    return `Привет, ${name}!`;
}
console.log(greet());      // 'Привет, Гость!'
console.log(greet('Ваня')); // 'Привет, Ваня!'

🔍 Разбор:

• function имя(параметры) { тело } — классическое объявление
• return — возвращает значение (без return — undefined)
• После return код в функции НЕ выполняется!
• (параметры) => { тело } — стрелочная функция
• параметр = 'значение' — значение по умолчанию

💡 Полезный совет:

Одна функция — одна задача. Если функция делает «и это, и то» — разбей на две. Короткие функции легче тестировать и переиспользовать. Имена функций — глаголы: getUser, calculateTotal, showError.

⚠️ Типичная ошибка:

Забыть return. Без него функция возвращает undefined. И путать функцию с её вызовом: console.log(greet) — выведет код функции, а console.log(greet()) — результат.
