🐘 Что такое PHP и первая программа

🎯 Цель урока

Понять, что такое PHP, как он работает на сервере, и написать свою первую программу «Hello, World!».

📚 Теория

PHP (PHP: Hypertext Preprocessor) — это серверный язык программирования. В отличие от JavaScript, который выполняется в браузере, PHP работает НА СЕРВЕРЕ и генерирует HTML, который отправляется пользователю. 🖥️

Что нужно для работы:
• Веб-сервер (Apache, Nginx)
• Интерпретатор PHP
• Можно установить готовый набор: XAMPP, MAMP, OpenServer, Laragon

Первая PHP-программа:

<?php
echo 'Привет, мир!';
?>


Как вставить PHP в HTML:
<!DOCTYPE html>
<html>
<head>
    <title>Моя страница</title>
</head>
<body>
    <h1><?php echo 'Привет из PHP!'; ?></h1>
    <p>Сегодня: <?php echo date('d.m.Y'); ?></p>
</body>
</html>


Файлы PHP имеют расширение .php. Сервер обрабатывает PHP-код, а браузер получает уже чистый HTML!

🔍 Разбор кода:

<?php — открывающий тег PHP (начало PHP-кода)
• ?> — закрывающий тег (если файл чисто PHP, его можно не ставить)
• echo — оператор вывода (выводит текст в HTML)
• date('d.m.Y') — встроенная функция для работы с датой
• Точка с запятой ; — КАЖДАЯ инструкция должна заканчиваться точкой с запятой!
• PHP код может быть в любом месте HTML-файла

💡 Полезный совет:

Установи OpenServer (Windows) или MAMP (Mac). Они содержат всё необходимое «из коробки»: Apache, PHP, MySQL. Запускай свои PHP-файлы через http://localhost/, а не просто открывая файл в браузере!

⚠️ Типичная ошибка:

Открывать .php файл напрямую в браузере (через File → Open). Браузер не умеет выполнять PHP! Файл должен обрабатываться сервером. Всегда используй http://localhost/ваш-файл.php.

✅ Итоги урока:

✅ PHP — серверный язык, выполняется НА СЕРВЕРЕ
✅ Код PHP пишется внутри <?php ... ?>
✅ echo — вывод текста
✅ Файлы с расширением .php
✅ Нужен веб-сервер (OpenServer, XAMPP, MAMP)
✅ Открывать через http://localhost/

🧠 Самостоятельная работа:

📝 Задание 1: Установи OpenServer (или аналог) и запусти его.

📝 Задание 2: Создай файл index.php в папке сервера и выведи «Привет, я изучаю PHP!».

📝 Задание 3: Выведи текущую дату и время с помощью функции date().
