🛡️ Безопасность: фильтрация и валидация данных

🎯 Цель урока

Научиться защищать приложение от некорректных и опасных данных: фильтрация, валидация, экранирование вывода.

📚 Теория

Золотое правило безопасности:
Фильтруй ввод, экранируй вывод!

1. Фильтрация ввода:

// Фильтрация через filter_var
$email = $_POST['email'] ?? '';
if (filter_var($email, FILTER_VALIDATE_EMAIL)) {
    echo 'Email корректен';
} else {
    echo 'Некорректный email!';
}

// Другие фильтры:
FILTER_VALIDATE_INT    // целое число
FILTER_VALIDATE_URL    // URL
FILTER_SANITIZE_STRING // удалить теги (устарел)
FILTER_SANITIZE_EMAIL  // очистить email

// Приведение типов
$age = (int) $_POST['age'];  // точно число
$price = (float) $_POST['price'];


2. Экранирование вывода (защита от XSS):
// Плохо (XSS-уязвимость!):
echo $_POST['message'];

// Хорошо:
echo htmlspecialchars($_POST['message'], ENT_QUOTES, 'UTF-8');


3. Базовая валидация:
$errors = [];
if (empty($_POST['name'])) {
    $errors[] = 'Имя обязательно';
}
if (strlen($_POST['password']) < 6) {
    $errors[] = 'Пароль должен быть минимум 6 символов';
}
if (count($errors) > 0) {
    foreach ($errors as $error) {
        echo "<p>$error</p>";
    }
}

🔍 Разбор:

• filter_var($var, FILTER) — фильтрация и валидация
• htmlspecialchars() — ОБЯЗАТЕЛЬНО при выводе пользовательских данных!
• (int), (float) — приведение к типу
• empty() — проверка на пустоту
• Всегда проверяй данные на сервере (клиентскую проверку легко обойти)

💡 Полезный совет:

Создай функцию-помощник для безопасного вывода:

function e($str) {
    return htmlspecialchars($str, ENT_QUOTES, 'UTF-8');
}
echo e($_POST['name']);  // всегда безопасно!

⚠️ Типичная ошибка:

Выводить пользовательские данные без экранирования. echo $_POST['message']; — если пользователь ввёл <script>alert('взлом!')</script>, этот скрипт выполнится у всех посетителей!

✅ Итоги урока:

✅ Фильтруй ввод (filter_var, приведение типов)
✅ Экранируй вывод (htmlspecialchars())
✅ Проверяй обязательные поля (empty())
✅ Защита от XSS — экранирование вывода
✅ Никогда не доверяй пользовательским данным

🧠 Самостоятельная работа:

📝 Задание 1: Создай форму с полями имя, email, возраст. Проверь email через filter_var.

📝 Задание 2: Выведи все полученные данные, предварительно экранировав через htmlspecialchars().

📝 Задание 3: Попробуй ввести в поле <script>alert(1)</script>. Убедись, что с экранированием скрипт не выполняется.

🤖 Вопрос к размышлению:

Почему недостаточно проверять данные только в JavaScript на клиенте?
