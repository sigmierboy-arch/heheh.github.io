📁 Работа с файлами: чтение и запись

🎯 Цель урока

Научиться работать с файловой системой: читать, записывать, добавлять данные в файлы.

📚 Теория

Чтение файла:

// Прочитать весь файл в строку
$content = file_get_contents('data.txt');
echo $content;

// Прочитать в массив (каждая строка — элемент)
$lines = file('data.txt');
foreach ($lines as $line) {
    echo $line;
}


Запись в файл:
// Записать (перезапишет файл!)
$text = 'Новый текст';
file_put_contents('data.txt', $text);

// Добавить в конец (не перезаписывая)
file_put_contents('data.txt', $text, FILE_APPEND);

// Добавить с переводом строки
file_put_contents('data.txt', $text . PHP_EOL, FILE_APPEND);


Проверка существования:
if (file_exists('data.txt')) {
    echo 'Файл существует';
} else {
    echo 'Файла нет';
}


Практический пример — гостевая книга:
// Сохранение сообщения
$name = $_POST['name'] ?? 'Аноним';
$message = $_POST['message'] ?? '';
$entry = date('d.m.Y H:i') . " | $name: $message" . PHP_EOL;
file_put_contents('guestbook.txt', $entry, FILE_APPEND);

// Чтение всех сообщений
$messages = file('guestbook.txt');
foreach ($messages as $msg) {
    echo htmlspecialchars($msg) . '<br>';
}

🔍 Разбор:

• file_get_contents() — чтение в строку
• file() — чтение в массив строк
• file_put_contents() — запись (перезапись)
• FILE_APPEND — флаг добавления в конец
• PHP_EOL — символ переноса строки (кроссплатформенный)
• file_exists() — проверка существования

💡 Полезный совет:

Для простых задач (гостевая книга, логи, заметки) файлового хранения достаточно. Но для серьёзных проектов используй базы данных (MySQL) — о них в следующих уроках!

⚠️ Типичная ошибка:

Забыть про права доступа! PHP должен иметь права на запись в папку/файл. На сервере это обычно настроено, но на локальном может потребоваться chmod 777 для папки.
