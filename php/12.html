📅 Дата и время: функции date(), time(), strtotime()

🎯 Цель урока

Освоить работу с датами и временем в PHP: форматирование, timestamp, вычисление интервалов.

📚 Теория

1. Текущая дата и время:

echo date('d.m.Y');          // 31.12.2024
echo date('H:i:s');           // 14:30:00
echo date('d.m.Y H:i:s');     // 31.12.2024 14:30:00
echo date('l, j F Y');       // Tuesday, 31 December 2024


Форматы date():
• d — день (01-31)
• m — месяц (01-12)
• Y — год (2024)
• H — часы (00-23)
• i — минуты (00-59)
• s — секунды (00-59)
• l — день недели
• F — месяц словом

2. Timestamp и strtotime():
$timestamp = time();  // текущее время в секундах с 1970-01-01
echo time();  // 1700000000 (пример)

// Преобразование строки в timestamp
$ts = strtotime('next Monday');
$ts = strtotime('2024-12-31');
$ts = strtotime('+1 week');
$ts = strtotime('+2 days');
echo date('d.m.Y', $ts);


3. Разница между датами:
$date1 = strtotime('2024-01-01');
$date2 = strtotime('2024-12-31');
$diff = $date2 - $date1;
$days = $diff / (60 * 60 * 24);  // количество дней
echo "Разница: $days дней";


4. Часовой пояс:
date_default_timezone_set('Europe/Moscow');  // установить
echo date_default_timezone_get();  // узнать текущий

🔍 Разбор:

• date('формат') — форматирование даты
• time() — текущий Unix timestamp
• strtotime('строка') — текст → timestamp (магия!)
• Математика с timestamp — вычисление интервалов
• date_default_timezone_set() — установка часового пояса

💡 Полезный совет:

strtotime() — невероятно мощная функция! Она понимает фразы типа «next Monday», «+2 weeks», «first day of next month». Используй её для любых преобразований дат!

⚠️ Типичная ошибка:

Забыть установить часовой пояс. По умолчанию используется UTC, и время может отличаться от ожидаемого. Всегда ставь: date_default_timezone_set('Europe/Moscow');
