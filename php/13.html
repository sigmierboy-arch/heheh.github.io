🍪 Сессии и Куки: храним состояние пользователя

🎯 Цель урока

Понять разницу между куками и сессиями и научиться их использовать для хранения пользовательских данных.

📚 Теория

HTTP — протокол без состояния. Каждый запрос независим. Куки и сессии решают эту проблему.

1. Куки (Cookies) — хранятся В БРАУЗЕРЕ:

// Установить куку (на 1 час)
setcookie('username', 'Анна', time() + 3600, '/');

// Прочитать куку
if (isset($_COOKIE['username'])) {
    echo 'Привет, ' . $_COOKIE['username'];
}

// Удалить куку (установить в прошлом)
setcookie('username', '', time() - 3600, '/');


2. Сессии (Sessions) — хранятся НА СЕРВЕРЕ (безопаснее!):
// ВСЕГДА в начале скрипта (до любого вывода!)
session_start();

// Сохранить в сессию
$_SESSION['username'] = 'Анна';
$_SESSION['isLoggedIn'] = true;

// Прочитать
if (isset($_SESSION['username'])) {
    echo 'Привет, ' . $_SESSION['username'];
}

// Удалить данные сессии
unset($_SESSION['username']);  // один ключ
session_destroy();  // вся сессия


Куки vs Сессии:
• Куки: на клиенте, ограничены по размеру (4KB), можно отключить
• Сессии: на сервере, безопаснее для sensitive данных, живут пока браузер открыт

Практический пример — счётчик посещений:
session_start();
if (!isset($_SESSION['visits'])) {
    $_SESSION['visits'] = 1;
} else {
    $_SESSION['visits']++;
}
echo "Вы зашли {$_SESSION['visits']} раз";

🔍 Разбор:

• setcookie(имя, значение, срок, путь) — установка куки
• $_COOKIE — суперглобальный массив кук
• session_start() — ОБЯЗАТЕЛЬНО в начале, до любого HTML!
• $_SESSION — суперглобальный массив сессии
• session_destroy() — полная очистка сессии
• Куки видны и редактируются пользователем, сессии — нет

💡 Полезный совет:

Используй сессии для авторизации и sensitive данных (на сервере, безопаснее). Используй куки для настроек (тема, язык) и «запомнить меня».

⚠️ Типичная ошибка:

Вызвать session_start() после вывода HTML. Это вызовет ошибку «Headers already sent». session_start() должен быть ПЕРВЫМ в скрипте, до любого echo или пробела!

✅ Итоги урока:

✅ Куки — в браузере (setcookie(), $_COOKIE)
✅ Сессии — на сервере (session_start(), $_SESSION)
✅ Сессии безопаснее для sensitive данных
✅ session_start() — строго до вывода
✅ Куки для настроек, сессии для авторизации
