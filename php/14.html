🗄️ Базы данных и MySQL: первые шаги

🎯 Цель урока

Понять основы реляционных баз данных, создать свою первую БД и таблицу в MySQL.

📚 Теория

База данных (БД) — организованное хранилище данных. MySQL — самая популярная реляционная БД для PHP.

Основные понятия:
• База данных — контейнер для таблиц
• Таблица — структура с колонками и строками
• Колонка (поле) — тип данных (имя, возраст, email)
• Строка (запись) — одна единица данных
• Первичный ключ (PRIMARY KEY) — уникальный идентификатор

Создание БД через phpMyAdmin:
1. Открыть http://localhost/phpmyadmin
2. Нажать «Создать БД»
3. Ввести имя (например, myapp)
4. Выбрать кодировку utf8mb4_general_ci

Создание таблицы SQL-запросом:

CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(150) UNIQUE NOT NULL,
    age INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);


Типы данных MySQL:
• INT — целое число
• VARCHAR(N) — строка переменной длины
• TEXT — длинный текст
• DATE, DATETIME, TIMESTAMP — даты
• DECIMAL(10,2) — деньги
• BOOLEAN (TINYINT) — true/false

🔍 Разбор:

• CREATE TABLE имя — создать таблицу
• id INT AUTO_INCREMENT PRIMARY KEY — автоинкрементный ID
• VARCHAR(100) NOT NULL — строка до 100 символов, обязательна
• UNIQUE — значение должно быть уникальным
• DEFAULT CURRENT_TIMESTAMP — значение по умолчанию
• utf8mb4 — кодировка для полной поддержки Unicode (включая эмодзи)

💡 Полезный совет:

Всегда создавай id с AUTO_INCREMENT PRIMARY KEY для каждой таблицы. Это лучшая практика. Для кодировки выбирай utf8mb4_general_ci — она поддерживает все языки и эмодзи.

⚠️ Типичная ошибка:

Забыть про кодировку или выбрать utf8 вместо utf8mb4. С utf8 эмодзи и некоторые символы не сохранятся! Всегда utf8mb4.

✅ Итоги урока:

✅ БД — организованное хранилище
✅ Таблицы состоят из колонок и строк
✅ PRIMARY KEY + AUTO_INCREMENT — ID
✅ Типы: INT, VARCHAR, TEXT, TIMESTAMP
✅ Кодировка: utf8mb4_general_ci
