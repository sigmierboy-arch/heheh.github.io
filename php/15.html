🔗 PHP + MySQL: подключение и запросы (PDO)

🎯 Цель урока

Научиться подключаться к MySQL из PHP и выполнять основные CRUD-операции (создание, чтение, обновление, удаление).

📚 Теория

PDO (PHP Data Objects) — современный и безопасный способ работы с БД.

1. Подключение:

$host = 'localhost';
$dbname = 'myapp';
$user = 'root';
$pass = '';

try {
    $pdo = new PDO(
        "mysql:host=$host;dbname=$dbname;charset=utf8mb4",
        $user,
        $pass,
        [
            PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC
        ]
    );
} catch (PDOException $e) {
    die('Ошибка подключения: ' . $e->getMessage());
}


2. SELECT (получить данные):
// Простой запрос
$stmt = $pdo->query('SELECT * FROM users');
$users = $stmt->fetchAll();
foreach ($users as $user) {
    echo $user['name'] . '<br>';
}

// С параметрами (ЗАЩИЩЁННЫЙ!)
$stmt = $pdo->prepare('SELECT * FROM users WHERE age > :age');
$stmt->execute(['age' => 18]);
$adults = $stmt->fetchAll();


3. INSERT (добавить):
$stmt = $pdo->prepare('INSERT INTO users (name, email, age) VALUES (:name, :email, :age)');
$stmt->execute([
    'name' => 'Иван',
    'email' => 'ivan@mail.com',
    'age' => 30
]);
echo 'Добавлен пользователь с ID: ' . $pdo->lastInsertId();


4. UPDATE (обновить):
$stmt = $pdo->prepare('UPDATE users SET age = :age WHERE id = :id');
$stmt->execute(['age' => 31, 'id' => 1]);


5. DELETE (удалить):
$stmt = $pdo->prepare('DELETE FROM users WHERE id = :id');
$stmt->execute(['id' => 3]);

🔍 Разбор:

• new PDO(DSN, user, pass) — подключение
• ERRMODE_EXCEPTION — ошибки как исключения
• FETCH_ASSOC — возвращать ассоциативные массивы
• prepare() + execute() — ПОДГОТОВЛЕННЫЕ запросы (защита от SQL-инъекций!)
• :name — именованные плейсхолдеры
• fetchAll() — все строки, fetch() — одна строка

💡 Полезный совет:

ВСЕГДА используй подготовленные запросы (prepare/execute) с плейсхолдерами. Никогда не вставляй переменные напрямую в SQL-строку! Это защита от SQL-инъекций.

⚠️ Типичная ошибка:

Формировать запрос так: "SELECT * FROM users WHERE name = '$name'". Это SQL-ИНЪЕКЦИЯ! Злоумышленник может уничтожить всю БД. Всегда используй prepare() + execute()!
