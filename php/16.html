📊 Работа с формами и БД вместе

🎯 Цель урока

Связать формы и базу данных в единое приложение: создание, чтение, обновление и удаление записей.

📚 Теория

CRUD — четыре основные операции:
• Create — создать
• Read — прочитать
• Update — обновить
• Delete — удалить

Практический пример — список задач:

// index.php — единая точка входа
require_once 'db.php';  // подключение к БД

// Определяем действие
$action = $_GET['action'] ?? 'list';

switch ($action) {
    case 'add':
        // Показать форму добавления или обработать
        if ($_SERVER['REQUEST_METHOD'] === 'POST') {
            $title = $_POST['title'] ?? '';
            $stmt = $pdo->prepare('INSERT INTO todos (title) VALUES (:title)');
            $stmt->execute(['title' => $title]);
            header('Location: index.php');  // редирект после POST
            exit;
        }
        // Показать форму
        require 'templates/add.php';
        break;
        
    case 'delete':
        $id = $_GET['id'] ?? 0;
        $stmt = $pdo->prepare('DELETE FROM todos WHERE id = :id');
        $stmt->execute(['id' => $id]);
        header('Location: index.php');
        exit;
        
    case 'edit':
        $id = $_GET['id'] ?? 0;
        if ($_SERVER['REQUEST_METHOD'] === 'POST') {
            $stmt = $pdo->prepare('UPDATE todos SET title = :title WHERE id = :id');
            $stmt->execute(['title' => $_POST['title'], 'id' => $id]);
            header('Location: index.php');
            exit;
        }
        $stmt = $pdo->prepare('SELECT * FROM todos WHERE id = :id');
        $stmt->execute(['id' => $id]);
        $todo = $stmt->fetch();
        require 'templates/edit.php';
        break;
        
    default:
        // Список всех задач
        $todos = $pdo->query('SELECT * FROM todos ORDER BY id DESC')->fetchAll();
        require 'templates/list.php';
}


Паттерн Post/Redirect/Get (PRG):
После обработки POST — всегда делай редирект. Это prevents повторную отправку формы при обновлении страницы!

🔍 Разбор:

• Одна точка входа (index.php?action=...)
• switch маршрутизирует запросы
• После POST — header('Location: ...') (редирект!)
• Шаблоны в отдельной папке templates/
• Чистый и организованный код

💡 Полезный совет:

Всегда используй Post/Redirect/Get (PRG): после обработки POST-запроса делай редирект на GET. Это prevents дублирование данных при обновлении страницы.

⚠️ Типичная ошибка:

Не делать редирект после обработки POST. Пользователь нажимает F5 — и данные отправляются повторно. Дубли в БД!
