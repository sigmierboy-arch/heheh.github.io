📤 Загрузка файлов на сервер

🎯 Цель урока

Научиться обрабатывать загрузку файлов через формы и безопасно сохранять их на сервере.

📚 Теория

HTML-форма для загрузки:

<form method="POST" enctype="multipart/form-data">
    <input type="file" name="avatar">
    <button type="submit">Загрузить</button>
</form>


Обработка в PHP:
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $file = $_FILES['avatar'];
    
    // Проверки
    if ($file['error'] !== UPLOAD_ERR_OK) {
        die('Ошибка загрузки');
    }
    
    // Проверка размера (например, макс 5MB)
    if ($file['size'] > 5 * 1024 * 1024) {
        die('Файл слишком большой');
    }
    
    // Проверка типа
    $allowedTypes = ['image/jpeg', 'image/png', 'image/gif'];
    if (!in_array($file['type'], $allowedTypes)) {
        die('Недопустимый тип файла');
    }
    
    // Уникальное имя
    $ext = pathinfo($file['name'], PATHINFO_EXTENSION);
    $newName = uniqid('img_') . '.' . $ext;
    $uploadPath = 'uploads/' . $newName;
    
    // Перемещение из временной папки
    if (move_uploaded_file($file['tmp_name'], $uploadPath)) {
        echo 'Файл загружен: ' . $newName;
    }
}


$_FILES содержит:
• name — оригинальное имя
• type — MIME-тип
• size — размер в байтах
• tmp_name — временный путь
• error — код ошибки (0 = успех)

🔍 Разбор:

• enctype="multipart/form-data" — ОБЯЗАТЕЛЬНО в форме!
• $_FILES['имя_поля'] — данные о файле
• uniqid() — генерация уникального имени
• pathinfo() — получение расширения
• move_uploaded_file() — перемещение из временной папки
• ВСЕГДА проверяй тип и размер!

💡 Полезный совет:

Генерируй уникальные имена файлов (uniqid()), чтобы избежать конфликтов. Сохраняй оригинальное имя в БД отдельно, если нужно. Ограничивай размер и тип файлов.

⚠️ Типичная ошибка:

Забыть enctype="multipart/form-data" в форме. Без этого $_FILES будет пустым! И доверять MIME-типу из $_FILES['type'] — он идёт от клиента, его можно подделать.

✅ Итоги урока:

✅ enctype="multipart/form-data" — обязательно
✅ $_FILES — информация о файле
✅ Проверка размера и типа
✅ move_uploaded_file() — сохранение
✅ Уникальные имена через uniqid()
