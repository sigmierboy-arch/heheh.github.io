🔐 Авторизация и регистрация: хеширование паролей

🎯 Цель урока

Научиться создавать безопасную систему регистрации и авторизации с хешированием паролей.

📚 Теория

НИКОГДА не храните пароли в открытом виде!

Регистрация:

// register.php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $username = $_POST['username'] ?? '';
    $password = $_POST['password'] ?? '';
    
    // Хеширование пароля
    $hashedPassword = password_hash($password, PASSWORD_DEFAULT);
    
    // Сохранение в БД
    $stmt = $pdo->prepare('INSERT INTO users (username, password) VALUES (:username, :password)');
    $stmt->execute([
        'username' => $username,
        'password' => $hashedPassword  // хеш, не пароль!
    ]);
    
    echo 'Регистрация успешна!';
}


Авторизация (вход):
// login.php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $username = $_POST['username'] ?? '';
    $password = $_POST['password'] ?? '';
    
    // Ищем пользователя
    $stmt = $pdo->prepare('SELECT * FROM users WHERE username = :username');
    $stmt->execute(['username' => $username]);
    $user = $stmt->fetch();
    
    // Проверяем пароль
    if ($user && password_verify($password, $user['password'])) {
        session_start();
        $_SESSION['user_id'] = $user['id'];
        $_SESSION['username'] = $user['username'];
        header('Location: dashboard.php');
        exit;
    } else {
        echo 'Неверный логин или пароль';
    }
}


Проверка авторизации на других страницах:
session_start();
if (!isset($_SESSION['user_id'])) {
    header('Location: login.php');
    exit;
}
// Пользователь авторизован — показываем контент


Выход:
session_start();
session_destroy();
header('Location: login.php');

🔍 Разбор:

• password_hash($pass, PASSWORD_DEFAULT) — безопасное хеширование
• password_verify($pass, $hash) — проверка пароля
• НИКОГДА не храни пароли в открытом виде
• Хеш нельзя «расшифровать» обратно
• PASSWORD_DEFAULT — использует лучший доступный алгоритм (сейчас bcrypt)

💡 Полезный совет:

Всегда используй password_hash() и password_verify(). Не изобретай своё шифрование! PHP сам выбирает лучший алгоритм и автоматически добавляет «соль» (salt) для защиты от радужных таблиц.

⚠️ Типичная ошибка:

Хранить пароли в БД как есть или использовать md5()/sha1(). Это небезопасно! Только password_hash() с PASSWORD_DEFAULT.
