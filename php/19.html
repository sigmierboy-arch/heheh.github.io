📧 Отправка писем: функция mail() и PHPMailer

🎯 Цель урока

Научиться отправлять электронные письма из PHP-скриптов.

📚 Теория

1. Встроенная функция mail():

$to = 'user@example.com';
$subject = 'Тема письма';
$message = 'Привет! Это тестовое письмо.';
$headers = 'From: sender@mysite.com' . "\r\n" .
           'Reply-To: sender@mysite.com' . "\r\n";

if (mail($to, $subject, $message, $headers)) {
    echo 'Письмо отправлено!';
} else {
    echo 'Ошибка отправки';
}


НО! Встроенная mail() имеет много недостатков: письма часто попадают в спам, нет аутентификации, сложно отправлять HTML-письма.

2. PHPMailer — современное решение 🔥:
// Подключение через Composer
// composer require phpmailer/phpmailer

use PHPMailer\\PHPMailer\\PHPMailer;
use PHPMailer\\PHPMailer\\Exception;

require 'vendor/autoload.php';

$mail = new PHPMailer(true);

try {
    // Настройки сервера
    $mail->isSMTP();
    $mail->Host = 'smtp.gmail.com';
    $mail->SMTPAuth = true;
    $mail->Username = 'your@gmail.com';
    $mail->Password = 'app_password';  // пароль приложения!
    $mail->SMTPSecure = PHPMailer::ENCRYPTION_STARTTLS;
    $mail->Port = 587;
    $mail->CharSet = 'UTF-8';
    
    // Отправитель и получатель
    $mail->setFrom('from@example.com', 'Мой Сайт');
    $mail->addAddress('to@example.com', 'Получатель');
    
    // Контент
    $mail->isHTML(true);
    $mail->Subject = 'Тема письма';
    $mail->Body = '<h1>Привет!</h1><p>Это <b>HTML</b> письмо</p>';
    $mail->AltBody = 'Привет! Это текстовое письмо';
    
    $mail->send();
    echo 'Письмо отправлено!';
} catch (Exception $e) {
    echo "Ошибка: {$mail->ErrorInfo}";
}

🔍 Разбор:

• mail() — встроенная, но ограниченная
• PHPMailer — библиотека, устанавливается через Composer
• isSMTP() — отправка через SMTP-сервер (надёжно!)
• isHTML(true) — HTML-письма с форматированием
• AltBody — текстовая версия для клиентов без HTML
• Для Gmail нужен «пароль приложения» (не основной пароль!)

💡 Полезный совет:

Всегда используй PHPMailer (или аналоги) вместо mail(). С SMTP-аутентификацией письма доходят надёжнее и реже попадают в спам. Установка через Composer: composer require phpmailer/phpmailer.

⚠️ Типичная ошибка:

Использовать основной пароль от Gmail в PHPMailer. Google блокирует такие попытки! Нужно создать «Пароль приложения» в настройках безопасности Google-аккаунта.
