📦 Переменные, типы данных и вывод

🎯 Цель урока

Научиться создавать переменные в PHP, понимать основные типы данных и освоить разные способы вывода информации.

📚 Теория

Переменные в PHP начинаются со знака $:

<?php
$name = 'Анна';      // строка
$age = 25;           // целое число
$price = 19.99;      // дробное число
$isAdmin = true;     // булево значение
$nothing = null;     // null (отсутствие значения)

// Вывод переменных
echo $name;
echo "Меня зовут $name, мне $age лет";  // двойные кавычки — подстановка!
echo 'Меня зовут ' . $name;             // конкатенация через точку
?>


Типы данных в PHP:
• string — строка (в кавычках)
• integer — целое число
• float/double — дробное число
• boolean — true/false
• null — «ничего»
• array — массив
• object — объект

Способы вывода:
echo 'Текст';           // просто вывод (можно несколько)
print 'Текст';          // как echo, но возвращает 1
var_dump($variable);    // вывод с типом и значением (для отладки!)
print_r($array);        // удобный вывод массивов


Проверка типа:
var_dump($name);   // string(4) "Анна"
echo gettype($age); // integer

🔍 Разбор:

• $ — ВСЕ переменные начинаются с доллара
• "текст $var" — в двойных кавычках переменные подставляются
• 'текст $var' — в одинарных кавычках НЕТ подстановки
• . — оператор КОНКАТЕНАЦИИ (склеивания строк), не плюс!
• var_dump() — твой лучший друг для отладки
• PHP чувствителен к регистру: $name и $Name — разные переменные

💡 Полезный совет:

Используй var_dump() для отладки! Он показывает и тип, и значение. Когда не понимаешь, что в переменной — пиши var_dump($var); и смотри.

⚠️ Типичная ошибка:

Забыть знак $ перед переменной. name = 'Анна'; — ОШИБКА! В PHP переменные ВСЕГДА с долларом: $name = 'Анна';. И конкатенация через ТОЧКУ, не через плюс: 'Привет, ' . $name.

✅ Итоги урока:

✅ Переменные: $имя = значение;
✅ Типы: string, integer, float, boolean, null
✅ Вывод: echo, print, var_dump()

✅ Двойные кавычки — подстановка переменных

🧠 Самостоятельная работа:

📝 Задание 1: Создай переменные: имя, возраст, город. Выведи их через echo с двойными кавычками.

📝 Задание 2: Выведи типы всех переменных через var_dump().

📝 Задание 3: Попробуй конкатенацию: создай полную строку из нескольких переменных через точку.
