Консолидировать все знания и создать завершённое веб-приложение — блог на чистом PHP с базой данных.

📚 Техническое задание (ТЗ) на проект

Создай блог со следующей структурой:

Структура проекта:

/blog
    /config
        database.php      // подключение к БД
    /includes
        header.php         // шапка сайта
        footer.php         // подвал
        auth.php           // проверка авторизации
    /uploads              // загруженные изображения
    /templates            // HTML-шаблоны
    index.php             // главная (список постов)
    post.php              // отдельный пост
    admin.php             // админка (CRUD постов)
    login.php             // вход
    register.php          // регистрация
    logout.php            // выход


Функционал:

1. Публичная часть:
• Главная страница: список постов (заголовок, дата, краткое описание)
• Страница поста: полный текст, изображения
• Комментарии к постам (имя, текст, дата)
• Пагинация (по 5 постов на странице)

2. Админ-панель:
• Вход по логину/паролю
• Создание/редактирование/удаление постов
• Загрузка изображений в посты
• Модерация комментариев (удаление)

3. База данных:
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE posts (
    id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    content TEXT NOT NULL,
    image VARCHAR(255),
    user_id INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

CREATE TABLE comments (
    id INT AUTO_INCREMENT PRIMARY KEY,
    post_id INT NOT NULL,
    author VARCHAR(100) NOT NULL,
    content TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (post_id) REFERENCES posts(id) ON DELETE CASCADE
);


4. Безопасность:
• Пароли хешируются (password_hash())
• Подготовленные запросы (PDO)
• Экранирование вывода (htmlspecialchars())
• Защита от XSS и SQL-инъекций
• Проверка авторизации на админ-страницах

5. Дополнительные фичи (опционально):
• Теги/категории для постов
• Поиск по блогу
• RSS-лента
• ЧПУ (человеко-понятные URL)

🔍 Архитектура:

• Точка входа — index.php
• Маршрутизация через GET-параметры
• Шаблоны отдельно от логики
• PDO для работы с БД
• Сессии для авторизации
• Post/Redirect/Get
