🔢 Операторы и условные конструкции

🎯 Цель урока

Освоить операторы PHP и научиться управлять потоком выполнения с помощью условных конструкций.

📚 Теория

1. Арифметические операторы:

$a = 10;
$b = 3;
echo $a + $b;  // 13
echo $a - $b;  // 7
echo $a * $b;  // 30
echo $a / $b;  // 3.333...
echo $a % $b;  // 1 (остаток)
echo $a ** $b; // 1000 (10 в 3-й степени)


2. Операторы сравнения:
var_dump(5 == '5');   // true (нестрогое)
var_dump(5 === '5');  // false (строгое, разные типы)
var_dump(5 != 3);    // true
var_dump(5 !== '5');  // true (строгое неравенство)
var_dump(5 < 10);     // true
var_dump(5 <= 5);     // true


3. Условный оператор if/else:
$age = 20;
if ($age >= 18) {
    echo 'Можно голосовать!';
} elseif ($age >= 16) {
    echo 'Почти взрослый';
} else {
    echo 'Ещё рано';
}


4. Тернарный оператор:
$status = $age >= 18 ? 'Взрослый' : 'Ребёнок';


5. switch/case:
$day = 'суббота';
switch ($day) {
    case 'понедельник':
        echo 'Тяжёлый день 😩';
        break;
    case 'пятница':
        echo 'Ура! 🎉';
        break;
    default:
        echo 'Обычный день';
}

🔍 Разбор:

• === — строгое сравнение (рекомендуется!)
• == — нестрогое (приводит типы, избегай)
• if/elseif/else — классические условия
• тернарный оператор — короткий if-else в одну строку
• switch — для множества вариантов одного значения
• break — обязателен в switch!

💡 Полезный совет:

Всегда используй === (строгое сравнение). В PHP 0 == false вернёт true (потому что нестрогое сравнение приводит типы), что может привести к трудноуловимым багам.

⚠️ Типичная ошибка:

Забыть break в switch. Без break выполнение «провалится» во все следующие case! И путать = (присваивание) и == (сравнение).
