🔄 Циклы: for, while, foreach

🎯 Цель урока

Освоить все виды циклов в PHP: for, while, do-while и специальный foreach для массивов.

📚 Теория

1. for — когда знаем количество итераций:

for ($i = 0; $i < 5; $i++) {
    echo "Итерация №$i";
}


2. while — пока условие true:
$count = 0;
while ($count < 3) {
    echo "Счёт: $count";
    $count++;
}


3. do-while — минимум один раз:
$x = 10;
do {
    echo "Выполнится хотя бы раз";
    $x++;
} while ($x < 5);


4. foreach — специально для массивов 🔥:
$fruits = ['яблоко', 'банан', 'апельсин'];
foreach ($fruits as $fruit) {
    echo "$fruit";
}

// С ключами:
$user = ['name' => 'Анна', 'age' => 25];
foreach ($user as $key => $value) {
    echo "$key: $value";
}


Управление циклами:
break;     // выйти из цикла
continue;  // пропустить текущую итерацию

🔍 Разбор:

• for (начало; условие; шаг) — классический цикл со счётчиком
• while (условие) — проверка ДО каждой итерации
• do-while — проверка ПОСЛЕ (минимум 1 раз)
• foreach ($arr as $item) — перебор массива
• foreach ($arr as $key => $value) — перебор с ключами
• break — выход, continue — пропуск

💡 Полезный совет:

Используй foreach для массивов — он самый удобный и читаемый. for — когда нужен индекс. while — когда неизвестно количество итераций.

⚠️ Типичная ошибка:

Бесконечный цикл! Если условие никогда не станет false — скрипт зависнет. Особенно часто забывают инкремент в while: $i++.
