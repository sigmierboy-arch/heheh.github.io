📋 Массивы: создание и основные функции

🎯 Цель урока

Научиться создавать все типы массивов в PHP и использовать основные функции для работы с ними.

📚 Теория

1. Индексированный массив (простой список):

$fruits = ['яблоко', 'банан', 'апельсин'];
// или старый синтаксис:
$fruits = array('яблоко', 'банан', 'апельсин');

echo $fruits[0];  // яблоко
echo $fruits[1];  // банан
$fruits[] = 'киви';  // добавить в конец


2. Ассоциативный массив (ключ-значение):
$user = [
    'name' => 'Анна',
    'age' => 25,
    'city' => 'Москва',
    'isAdmin' => true
];
echo $user['name'];  // Анна
$user['email'] = 'anna@mail.com';  // добавить


3. Многомерный массив:
$users = [
    ['name' => 'Анна', 'age' => 25],
    ['name' => 'Иван', 'age' => 30],
    ['name' => 'Катя', 'age' => 22]
];
echo $users[1]['name'];  // Иван


Полезные функции для массивов:
count($arr);           // количество элементов
array_push($arr, $item);  // добавить в конец
array_pop($arr);       // удалить с конца
array_shift($arr);     // удалить с начала
array_unshift($arr, $item); // добавить в начало
in_array($item, $arr); // проверить наличие
array_keys($arr);      // получить все ключи
array_values($arr);    // получить все значения
array_merge($arr1, $arr2); // объединить массивы
sort($arr);            // сортировка

🔍 Разбор:

• [1, 2, 3] — короткий синтаксис массива (PHP 5.4+)
• ['key' => 'value'] — ассоциативный массив
• $arr[] = 'новый' — добавить в конец (проще чем array_push)
• count() — длина массива
• in_array() — проверка наличия значения

💡 Полезный совет:

Используй короткий синтаксис [] вместо array(). Для добавления в конец — просто $arr[] = $value (быстрее, чем array_push).

⚠️ Типичная ошибка:

Пытаться вывести массив через echo $arr;. Выведется Array и всё. Используй print_r($arr) или var_dump($arr) для просмотра содержимого!
