🔧 Функции: создание, параметры, return, область видимости

🎯 Цель урока

Научиться создавать собственные функции, работать с параметрами и возвращать результат.

📚 Теория

1. Объявление функции:

function greet($name) {
    return "Привет, $name!";
}
echo greet('Анна');  // Привет, Анна!


2. Параметры по умолчанию:
function greet($name = 'Гость') {
    return "Привет, $name!";
}
echo greet();       // Привет, Гость!
echo greet('Ваня'); // Привет, Ваня!


3. Типизация параметров (PHP 7+):
function sum(int $a, int $b): int {
    return $a + $b;
}
echo sum(5, 3);  // 8
// sum('текст', 3);  // ОШИБКА! TypeError


4. Несколько параметров и splat оператор:
function sumAll(...$numbers) {
    return array_sum($numbers);
}
echo sumAll(1, 2, 3, 4, 5);  // 15


5. Область видимости:
$globalVar = 'снаружи';
function test() {
    global $globalVar;  // получить доступ к глобальной
    echo $globalVar;
    $localVar = 'внутри';  // только внутри функции
}

🔍 Разбор:

• function имя($параметр) — объявление
• return — возврат значения (без return — null)
• ($name = 'Гость') — значение по умолчанию
• function sum(int $a, int $b): int — строгая типизация
• ...$numbers — собрать все аргументы в массив
• global — доступ к глобальной переменной (избегай!)

💡 Полезный совет:

Используй типизацию параметров и возвращаемого значения! Это делает код предсказуемее и помогает отлавливать ошибки на раннем этапе. PHP 8 добавил ещё больше возможностей типизации.

⚠️ Типичная ошибка:

Забыть return. Функция без return возвращает null. И пытаться использовать переменную из функции снаружи — она там не видна!

Почему использование global считается плохой практикой?

🎉 Бонус:

Функции — это твои личные инструменты. Ты создаёшь свою библиотеку команд! Хорошая функция — как хороший нож: делает одну задачу, но делает её отлично. 🔧
