📝 Строки: функции для работы с текстом

🎯 Цель урока

Освоить основные строковые функции PHP для обработки текста.

📚 Теория

Основные строковые функции:

$str = 'Привет, Мир!';

// Длина строки
echo strlen($str);  // 13 (для латиницы)
echo mb_strlen($str);  // 13 (для UTF-8, русский текст!)

// Регистр
echo strtoupper($str);  // ПРИВЕТ, МИР!
echo strtolower($str);  // привет, мир!
echo ucfirst('привет'); // Привет (первая буква заглавная)
echo ucwords('привет мир'); // Привет Мир

// Поиск
$pos = strpos($str, 'Мир');  // 8 (позиция) или false
if ($pos !== false) { echo 'Найдено!'; }
str_contains($str, 'Мир');  // true/false (PHP 8+)

// Замена
echo str_replace('Мир', 'PHP', $str);  // Привет, PHP!
echo str_ireplace('мир', 'PHP', $str); // без учёта регистра

// Извлечение
echo substr($str, 0, 6);  // Привет
echo substr($str, 8);     // Мир!

// Удаление пробелов
echo trim('  текст  ');  // 'текст'

// Разбиение и склеивание
$arr = explode(', ', $str);  // ['Привет', 'Мир!']
echo implode(' | ', $arr);   // Привет | Мир!

🔍 Разбор:

• mb_strlen() — для русского текста (многобайтовые строки!)
• strpos() — возвращает false если не найдено (ПРОВЕРЯТЬ через !==)
• str_replace() — замена всех вхождений
• explode() — строка → массив
• implode() — массив → строка
• trim() — удаление пробелов по краям

💡 Полезный совет:

Для русского языка ВСЕГДА используй mb_* функции: mb_strlen(), mb_strpos(), mb_substr(). Обычные функции считают кириллические символы как 2 байта.

⚠️ Типичная ошибка:

Проверять strpos() как if (strpos($str, 'текст')). Если подстрока в начале (позиция 0), условие не сработает (0 == false)! Правильно: if (strpos($str, 'текст') !== false).

✅ Итоги урока:

✅ strlen(), mb_strlen() — длина
✅ strpos() — поиск (проверять через !==)
✅ str_replace() — замена
✅ substr() — извлечение
✅ explode()/implode() — преобразование
✅ Для русского — mb_* функции
