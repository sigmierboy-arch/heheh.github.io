📂 Подключение файлов: include, require, include_once, require_once

🎯 Цель урока

Научиться организовывать код, разделяя его на файлы, и подключать их с помощью include и require.

📚 Теория

Зачем разбивать код на файлы?
• Переиспользование (шапка и подвал на всех страницах)
• Чистота и организация
• Лёгкость поддержки

4 способа подключения:

// include — если файла нет, WARNING, скрипт продолжается
include 'header.php';

// require — если файла нет, FATAL ERROR, скрипт ОСТАНАВЛИВАЕТСЯ
require 'config.php';

// _once — подключить ТОЛЬКО один раз (даже если вызвано несколько раз)
include_once 'functions.php';
require_once 'database.php';  // САМЫЙ частый вариант!


Практический пример:
// header.php
<!DOCTYPE html>
<html>
<head>
    <title><?= $pageTitle ?? 'Мой сайт' ?></title>
</head>
<body>
    <header>...</header>

// index.php
<?php
$pageTitle = 'Главная';
require_once 'header.php';
?>
    <main>Контент страницы</main>
<?php
require_once 'footer.php';
?>


Когда что использовать:
• require — для ОБЯЗАТЕЛЬНЫХ файлов (конфиг, БД)
• include — для НЕОБЯЗАТЕЛЬНЫХ (баннер, виджет)
• _once — почти ВСЕГДА (чтобы не было дублирования)

🔍 Разбор:

• include — Warning если нет файла (скрипт продолжается)
• require — Fatal Error если нет файла (скрипт стоп)
• _once — гарантирует однократное подключение
• require_once — самый надёжный и частый вариант
• <?= $var ?> — короткая запись echo

💡 Полезный совет:

Структурируй проект так:

/project
    /includes
        header.php
        footer.php
        functions.php
    /config
        database.php
    index.php
    about.php

Используй require_once для всего критичного.

⚠️ Типичная ошибка:

Подключать один и тот же файл несколько раз (например, с функциями). Без _once будет ошибка «Cannot redeclare function». Всегда используй require_once для файлов с функциями!

✅ Итоги урока:

✅ include — мягкое подключение (Warning)
✅ require — жёсткое подключение (Fatal Error)
✅ _once — только один раз
✅ require_once — лучший выбор для обязательных файлов
✅ Разделяй код на логические модули

🧠 Самостоятельная работа:

📝 Задание 1: Создай три файла: header.php, footer.php, index.php. Подключи шапку и подвал в index.

📝 Задание 2: Создай файл functions.php с функцией. Подключи его через require_once и используй функцию.

📝 Задание 3: Намеренно попробуй подключить несуществующий файл через include и через require. Сравни результат.
