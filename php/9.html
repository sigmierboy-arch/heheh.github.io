🌐 GET и POST запросы: принимаем данные от пользователя

🎯 Цель урока

Научиться принимать данные от пользователя через URL (GET) и формы (POST), используя суперглобальные массивы.

📚 Теория

$_GET — данные из URL (видны в адресной строке):

// URL: page.php?name=Анна&age=25
echo $_GET['name'];  // Анна
echo $_GET['age'];   // 25

// Проверка существования
if (isset($_GET['name'])) {
    echo 'Привет, ' . $_GET['name'];
}

// Значение по умолчанию
$name = $_GET['name'] ?? 'Гость';  // PHP 7+


$_POST — данные из форм (не видны в URL):
// HTML-форма
<form method="POST" action="process.php">
    <input name="username">
    <input name="password" type="password">
    <button type="submit">Войти</button>
</form>

// process.php
$username = $_POST['username'] ?? '';
$password = $_POST['password'] ?? '';
echo "Логин: $username";


$_REQUEST — содержит и GET, и POST (избегай, небезопасно!)

Когда что использовать:
• GET — поиск, фильтры, пагинация (данные в URL)
• POST — логин, отправка форм, личные данные

🔍 Разбор:

• $_GET['key'] — значение из URL
• $_POST['key'] — значение из формы
• isset() — проверка существования
• ?? — null coalescing оператор (если нет — значение по умолчанию)
• GET виден в адресной строке, POST — нет
• Всегда проверяй и фильтруй пользовательский ввод!

💡 Полезный совет:

Используй null coalescing оператор ?? для значений по умолчанию:

$name = $_GET['name'] ?? 'Гость';

Это короче и элегантнее, чем isset() ? ... : ...

⚠️ Типичная ошибка:

Доверять пользовательскому вводу! ВСЕГДА проверяй и фильтруй данные из $_GET и $_POST. Никогда не выводи их напрямую в HTML без экранирования (XSS-уязвимость!).

✅ Итоги урока:

✅ $_GET — данные из URL
✅ $_POST — данные из форм
✅ isset() — проверка наличия
✅ ?? — значение по умолчанию
✅ GET — для поиска/фильтров, POST — для sensitive данных
