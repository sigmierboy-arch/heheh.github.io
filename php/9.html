🌐 GET и POST запросы: принимаем данные от пользователя

🎯 Цель урока

Научиться принимать данные от пользователя через URL (GET) и формы (POST), используя суперглобальные массивы.

📚 Теория

$_GET — данные из URL (видны в адресной строке):\n

// URL: page.php?name=Анна&age=25\necho $_GET['name'];  // Анна\necho $_GET['age'];   // 25\n\n// Проверка существования\nif (isset($_GET['name'])) {\n    echo 'Привет, ' . $_GET['name'];\n}\n\n// Значение по умолчанию\n$name = $_GET['name'] ?? 'Гость';  // PHP 7+
\n\n$_POST — данные из форм (не видны в URL):\n
// HTML-форма\n<form method="POST" action="process.php">\n    <input name="username">\n    <input name="password" type="password">\n    <button type="submit">Войти</button>\n</form>\n\n// process.php\n$username = $_POST['username'] ?? '';\n$password = $_POST['password'] ?? '';\necho "Логин: $username";
\n\n$_REQUEST — содержит и GET, и POST (избегай, небезопасно!)\n\nКогда что использовать:\n• GET — поиск, фильтры, пагинация (данные в URL)\n• POST — логин, отправка форм, личные данные

🔍 Разбор:

• $_GET['key'] — значение из URL\n• $_POST['key'] — значение из формы\n• isset() — проверка существования\n• ?? — null coalescing оператор (если нет — значение по умолчанию)\n• GET виден в адресной строке, POST — нет\n• Всегда проверяй и фильтруй пользовательский ввод!

💡 Полезный совет:

Используй null coalescing оператор ?? для значений по умолчанию:\n

$name = $_GET['name'] ?? 'Гость';
\nЭто короче и элегантнее, чем isset() ? ... : ...

⚠️ Типичная ошибка:

Доверять пользовательскому вводу! ВСЕГДА проверяй и фильтруй данные из $_GET и $_POST. Никогда не выводи их напрямую в HTML без экранирования (XSS-уязвимость!).

✅ Итоги урока:

✅ $_GET — данные из URL\n✅ $_POST — данные из форм\n✅ isset() — проверка наличия\n✅ ?? — значение по умолчанию\n✅ GET — для поиска/фильтров, POST — для sensitive данных

🧠 Самостоятельная работа:

📝 Задание 1: Создай страницу hello.php, которая принимает ?name=Имя и выводит приветствие.\n\n📝 Задание 2: Создай форму обратной связи (имя, email, сообщение) и выведи полученные данные.\n\n📝 Задание 3: Реализуй проверку: если поле пустое — показать ошибку.
